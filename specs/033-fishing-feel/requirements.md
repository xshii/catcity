# 033 钓鱼手感与深度

- 状态：进行中
- 来源：2026-09-29 用户："请你仔细再思考设计一下，这个钓鱼怎么做得更好呢？"；确认："拉锯战要，鱼影要，开启音效"。

## 诊断（实机日志与反馈）

1. 上手门槛：首竿前要学会校准、左右瞄准、俯仰力度、下甩、快速上扬、倾斜追鱼六个动作，且几乎无引导（曾误以为小点是鱼、力度条含义不清、找不到校准键）。
2. 反馈薄：游戏关闭了声音；iPhone 网页不能振动；甩竿、咬钩、收线的爽感主要靠声音。
3. 遛鱼只有追踪：没有对抗、风险与"拉近"的过程。
4. 等待与选择空洞：落点和鱼饵的差别看不见。

原则：看得懂 → 手感好 → 有决策 → 有惊喜 → 短局（一条鱼 30–60 秒）。

## F1 拉锯战（Core + 画面）

- 鱼冲刺（现有预警后冲刺）时产生拉力：冲刺中竿尖须**拉到鱼的身后**（水面坐标 y 大于鱼 y 加容差，即朝玩家方向）才算顶住；否则鱼线张力按鱼的星级上升；不冲刺时张力回落。张力满则断线脱钩（reason `line-break`）。
- 输入仍是每 tick 的竿尖点（`FISH_MOTION_CONTROL`），不加命令；判定在 `minigames/angling-motion.ts`，数值在 `content/fishing/motion.ts`。张力随 run 保存（存档版本 +1）。
- 画面：圈外缘显示张力（渐红），冲刺中提示"往回拉！"；鱼影随累计进度靠近、变大。
- 平衡：模拟里老练玩家高星上鱼率不因拉锯下降超过设定上限；新手仍钓不到 4–5★；高星鱼冲刺更频繁、拉力更大。

## F2 鱼影（Core + 画面）

- 每个钓点的鱼影由种子与游戏时间推导（每游戏小时刷新一批），不存档：位置（方向、远近）、深浅、体型档（小/中/大，对应星级区间）；鱼种对玩家隐藏，只看体型。
- 落点靠近某条鱼影（在判定半径内）：该鱼种优先（仍须鱼饵、钓点与猫品种允许），咬口更快；鱼饵不对时鱼影"嗅一下离开"（咬口推迟）。远离鱼影仍可按现规则钓到常见鱼。
- Core 提供 `fishShadows(world, spotId)` 纯函数供画面绘制，`FISH_BEGIN`/抛竿用同一函数判定，画面不自行推导规则（015 规则 3）。
- 平衡：瞄准大鱼影提高高星出现率但不改变遛鱼难度；模拟覆盖。

## F3 首竿引导 + 自动校准（画面）

- 首次体感钓鱼逐步引导：左右瞄准 → 后仰加力 → 下甩抛竿 → 等"！"上扬 → 用圈罩住鱼；每步成功后出现下一步，可跳过。
- 首次抛竿前自动进入校准（提示"向下快甩两次"），无需找按钮；之后按钮仍在。

## F4 音效（画面）

- Web Audio 合成（不引入音频文件）：甩竿呼声、入水声、浮漂轻点（假咬口）、咬钩"噗"、收线嗡声（随进度）、张力吃紧、上鱼水花、断线。
- 设置里可关闭（按设备记住）；支持的浏览器用 `navigator.audioSession.type = 'ambient'` 跟随静音键；首次用户手势后才开启音频上下文。
- Android 同时振动；iOS 用更强的画面反馈（轻微震屏、闪光）代替振动。

## F5 落点与力度弧（画面）

- 力度条改为水面上的落点预测：虚线弧与落点圈随俯仰实时移动，精准区间在弧上标绿。
- F5b（实机反馈修订，用户："不应该是圈对准鱼影子就是合适的吗？比如靠近有鱼区就变绿如何"）：绿色只表示落点圈对准了鱼影（Core 判定这一竿会落在鱼影上），不再标力度区间；体感抛竿不再按力度区间判稳投，每一竿都有稳投加成，力度只定远近；按钮版仍按松开时的力度区间判定，蓄力条的绿段不变，水面不画区间。

## F6 提竿动效（画面）

来源：实机反馈，用户："钓竿拉起的动效能做一下吗"。只改画面：不改 Core、存档与命令。

- 提竿：一竿从咬钩进入遛鱼时，竿尖约 0.18 秒内快速扬起（先快后慢），略微过头后回落到扬起、弯曲的姿态；鱼线从竿尖直连浮漂。
- 遛鱼：竿保持扬起，弯曲随这一竿的 `tension`（按钮版的张力、体感的冲刺拉力）轻微变化，没有拉力时也略弯。
- 上鱼：钓到时竿再扬一次（约 0.3 秒），随后放回原位。不经遛鱼直接钓到的补给（罐头、金币袋）从原位扬起。
- 脱钩、断线、收竿离开：竿直接缓缓放回原位。
- 按钮与体感两种模式相同。`prefers-reduced-motion: reduce` 时不播放摆动，直接到最终姿态（遛鱼时扬起并随拉力弯曲，其余为原位）。
- 原位的画法与之前相同（栈桥到竿尖的一条直线）；抛竿预览与浮漂飞行仍从原位的竿尖算起。

## 验收
