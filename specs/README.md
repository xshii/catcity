# 功能规格（Specs）

每个功能或整改一个目录 `NNN-名称/`，是需求状态的唯一登记处。产品规则与数值仍在 `docs/` 与代码规格文件中维护，spec 只引用、不复制。

| 文件              | 内容                                                         |
| ----------------- | ------------------------------------------------------------ |
| `requirements.md` | 来源、目标、验收标准（可观察、可测试）、不做什么             |
| `design.md`       | 需要读的文件（按五类分组）、设计决策与取舍；已有文档只写链接 |
| `tasks.md`        | 带复选框的任务，勾选时写上验证证据（测试名、命令、产物路径） |

`提出` 状态只需 `requirements.md`；进入 `已确认` 后再补 `design.md` / `tasks.md`。

## 状态

| 状态   | 含义                                                             |
| ------ | ---------------------------------------------------------------- |
| 提出   | 记录了需求，尚未确认范围                                         |
| 已确认 | 用户确认范围与验收标准                                           |
| 进行中 | 有未完成任务                                                     |
| 验证中 | 代码完成，等待完整 Gate / Harness / 实机                         |
| 完成   | `npm run check` 与 Harness 通过、截图已查看，证据写进 `tasks.md` |
| 延后   | 明确不在当前范围                                                 |

AI 不得在没有证据时把状态改为"完成"。一次会话结束前更新本表与对应 `tasks.md`。

## 代码五类（渐进披露）

| 类别     | 位置                                                                                                     | 何时读             |
| -------- | -------------------------------------------------------------------------------------------------------- | ------------------ |
| 核心架构 | `src/core/*.ts`、`src/application/`、`src/main.ts`、`src/view/index.ts`                                  | 任何改动           |
| 玩法模块 | `src/core/{city,fishing}/`、`src/content/`、`src/minigames/`、`src/view/{city,fishing,shell,companion}/` | 改到对应功能时     |
| 体感     | `src/view/motion/`                                                                                       | 只在改传感器输入时 |
| 美工     | `src/view/art/`（绘图、调色板）与各模块样式                                                              | 换画面时           |
| 工具     | `harness/`、`src/debug/`、`src/platform/`、`tests/helpers/`、构建配置                                    | 改构建/验证/发布时 |
| 用例     | `tests/`                                                                                                 | 验证时             |
