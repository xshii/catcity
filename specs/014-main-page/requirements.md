## 5. 道路价格与拆路

| #   | 验收标准                                                                                                                                                            | 证据 |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- |
| 5.1 | 铺土路 10→30 金币，升级石路 20→40 金币（数值在 `src/content/city.ts`）                                                                                              |      |
| 5.2 | 新命令 `REMOVE_ROAD` 拆除已拥有草地上的道路，按路面部分退款（土路退 15、石路退 35，定义在 content），拆后该格可再建设；命令结果与其他命令一样记录并可回放           |      |
| 5.3 | 拆路规则：非草地 `INVALID_PLACEMENT`；未拥有 `LAND_NOT_OWNED`；没有道路 `NO_ROAD`；起始十字路口，或拆后任一建筑不再连到起始路网 `ROAD_IN_USE`；被拒绝时世界完全不变 |      |
| 5.4 | 地块卡在道路上提供"拆除道路 · 退 N 金币"，拆不了时禁用并说明原因                                                                                                    |      |

### 价格理由

原价铺路 10 仅为买地 50 的 1/5、猫咖 300 的 1/30，铺路几乎没有取舍。改为土路 30（买地的 60%，一格"地+路"80）、石路升级 40（一格石路共 70）：开局 1000 金币铺 10 格土路就等于一间猫咖，一格石路约等于一间猫咖 7 小时的收入，路网要规划。退款按投入的一半（土路 15，石路 (30+40)/2=35），拆错有代价但不至于不敢改。

### 拆路规则理由

- 道路只影响步行耗时，草地本身可走：猫站在该格或路线经过它都不阻止拆路，已排定的下一步时间仍然合法（草地是最慢步速），后续步按新地面计时。
- 建筑必须与起始十字路口所在路网相连（存档校验同样要求），所以拆路不能断开任何建筑；起始路口是路网根，不能拆。
- 与其他路段断开但不影响建筑的道路可以拆。
