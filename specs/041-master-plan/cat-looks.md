# 041 捏猫：外观五项、流浪猫开局与猫咪美容院（T-14、T-15）

- 来源（用户 2026-09-30）："不同的猫有不同的纹理吧，和脸型""田园猫支持选多种颜色""比如田园猫的白手套黑色……做一个简单的建模吧""别太复杂啦，人的游戏可以捏脸，猫的捏脸你也做一个吧，为了测试，可以增加一个随机按钮，初始猫咪就是可以捡来的流浪猫，第一次支持自定义，后续需要建猫咪美容院来改造"。
- 追问后的决定：流浪猫"第一次可以选品种，后续随剧情，不能改品种"；美容院"每次改造收一点费"。
- 依赖：T-13（颜色 token、对比度测试、品种轮廓）。配套：[ui-design.md](ui-design.md) 2.2、6.1；[design.md](design.md) 第 3 节。

## 1. 外观：五项

一只猫的样子由五项组成，每项从固定选项里选，直接存在猫身上（取代 `coat`）：

| 项   | 选项                                 |
| ---- | ------------------------------------ |
| 毛色 | 黑、灰、橘、奶油、白、棕             |
| 花纹 | 纯色、虎斑、重点色（脸、耳、尾巴深） |
| 白斑 | 无、手套、围兜、奶牛、双色           |
| 眼色 | 蓝、铜、黄绿                         |
| 脸型 | 圆、尖、长                           |

- 品种决定轮廓（T-13：布偶的腮毛和蓬松尾巴、英短的小圆耳和短尾），脸型在品种轮廓上改头形。名册头像、地图上的猫、河畔同伴、撸猫画面、邀请名单用同一套画法（R-15）。
- 每种毛色和它的描线对比度 ≥ 3:1；深色毛（黑、棕）用浅色描线。单测守护。
- 不做自动起名（例如黑色加手套叫"踏雪"），不做每只猫的随机差异。

## 2. 开局：捡到一只流浪猫（T-14）

- 新游戏开场："路边捡到一只流浪猫"，进入捏猫画面：
  - 选品种：田园猫、布偶、英短，每个写明钓鱼特长（田园猫没有专属鱼，写"什么鱼都愿意陪你钓"）；
  - 选五项外观，上方大图实时预览；
  - 🎲 **随机**：一键随机品种和五项，方便测试；
  - 确认后给它起名（T-25，用户 2026-09-30）：同一个起名框，预填第一个推荐名，可以输入或点选推荐名，留空用推荐名；确认后开始游戏，取消回到捏猫画面。
- 这是唯一一次能选品种。之后品种不能改：邀请来的猫是名单模板的品种，生出来的猫由遗传决定（"后续随剧情"）。
- 这只猫仍是 Mochi 的身份（性格、喜欢的鱼、性别，id `mochi`），品种、外观和名字由玩家定（名字见上一条，T-25）。
- 校验：初代猫的性格、喜好、喜欢的鱼、性别仍必须等于模板；**外观不再和模板比**（玩家定、美容院可改），只校验每项是合法选项；初始猫的品种是三种之一，其余初代猫的品种等于模板。
- 田园猫是新品种 `DOMESTIC`。开局选田园猫时，布偶才能引来的锦鲤、英短才能引来的月光鲤要等邀请对应品种的猫才能钓到。节奏与平衡模拟要在三种开局品种下都达标。
- 存档升一版并补拒绝样本；内容版本 +1。

## 3. 猫咪美容院（T-15）

- 新建筑 `CAT_SALON`（猫咪美容院），**1,500 金币**，一座城**最多 1 座**（`MAX_SALONS`，再建一座被拒绝，`BUILDING_LIMIT`；地块卡在已有美容院时不再列出它）。和别的建筑一样占一格、要挨着路网、可以免费搬移；不住猫、不接待猫咖的客人、没有收入。价格和上限在 `src/content/city.ts`。
- 建好后点它，操作卡为每只伙伴猫列出"给 <猫名> 改造"，点一只进入同一个捏猫画面（不显示品种那一排，确认按钮是"改造 · 50 金币"），**只改五项外观，不能改品种**；每次改造收费 `RESTYLE_PRICE`（**50 金币**）。
- 命令 `RESTYLE_CAT { catId, appearance }`：`appearance` 只有五项，多一个字段（比如品种）整条命令无效；依次检查 `NO_SALON`、`CAT_NOT_FOUND`、`INSUFFICIENT_COINS`、`APPEARANCE_UNCHANGED`，被拒绝时世界不变、不收费。金币先于外观检查，所以操作卡用这只猫现在的样子试算，就知道它能不能改造（只剩"没变化"时可以）；金币不够时按钮禁用，写"金币不足：需要 50，现有 N。"。外观不影响任何数值（单测：改造前后同样的一竿、时间、聊天和撸猫结果完全相同）。
- 存档 25（建筑类型多了一种）、内容 19（开工时 main 是存档 23、内容 15；合并前撸猫窗口、绝育、居民先用掉了内容 16–18 和存档 24）。

### 3.1 价格怎么定的

美容院没有收入，它的价格只会拖慢建城。`tests/simulation/economy.test.ts` 的目标区间不变，要求带上美容院之后仍然全部成立（三种开局品种都测）：

- 按原规划 12 块地都有用处，路网旁没有空地。带美容院的规划（`tests/helpers/city-player.ts` 的 `SALON_PLAN`）把路从 (5,6) 往南铺一格到 (5,7)，原来 (5,7) 的公寓挪到 (6,7)，美容院在 (4,7)；多一格路和两块地共 130 金币，16 只猫仍然都是客人。
- **最拖慢的玩家**是开局先攒钱建美容院、再照常建城的人（花出去的钱最晚开始赚钱）。

| 美容院价格 | 先建美容院的玩家住满城市（目标 12–20 小时） | 住满的城市连美容院的总价（目标 40,000–48,000） |
| ---------- | ------------------------------------------- | ---------------------------------------------- |
| 1,000      | 15.7 小时（944 分钟）                       | 45,360                                         |
| **1,500**  | **16.1 小时（964 分钟），第 26 分钟建成**   | **45,860**                                     |
| 3,000      | 17.1 小时（1,024 分钟）                     | 47,360                                         |
| 3,640      | 17.5 小时                                   | 48,000（上限）                                 |

总价是约束：价格不能超过 3,640。建城时间不是约束（4,000 也只要 17.7 小时）。取 1,500：模拟里钓鱼每现实分钟 25 金币，1,500 正好是一个现实小时的钓鱼收入，开局的 1,000 金币买不起（"后续"才建），离总价上限还有 2,140。原规划（没有美容院）的四个目标和 44,230 的总价不变。

## 4. 捏猫画面（两处共用）

- 独立的画面模块（纯模型加 DOM 应用），输入"能不能选品种"、确认按钮文字、初始外观，输出确认时的品种和外观或取消。开局捡猫（`view/cats/stray.ts`）和美容院（`view/cats/salon.ts`，从地图操作卡打开，关闭后焦点回到打开它的按钮）都用它。
- 每一项是一排点选按钮，当前选中的高亮；预览随选择实时变化；🎲 随机只改画面上的选择，确认之前不发命令。
- 可及性：只用键盘能走完；每个选项有读屏名；390×844、360×640 放得下，不横向滚动。
