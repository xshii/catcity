# 041 捏猫：外观五项、流浪猫开局与猫咪美容院（T-14、T-15）

- 来源（用户 2026-09-30）："不同的猫有不同的纹理吧，和脸型""田园猫支持选多种颜色""比如田园猫的白手套黑色……做一个简单的建模吧""别太复杂啦，人的游戏可以捏脸，猫的捏脸你也做一个吧，为了测试，可以增加一个随机按钮，初始猫咪就是可以捡来的流浪猫，第一次支持自定义，后续需要建猫咪美容院来改造"。
- 追问后的决定：流浪猫"第一次可以选品种，后续随剧情，不能改品种"；美容院"每次改造收一点费"。
- 依赖：T-13（颜色 token、对比度测试、品种轮廓）。配套：[ui-design.md](ui-design.md) 2.2、6.1；[design.md](design.md) 第 3 节。

## 1. 外观：五项

一只猫的样子由五项组成，每项从固定选项里选，直接存在猫身上（取代 `coat`）：

| 项   | 选项                                 |
| ---- | ------------------------------------ |
| 毛色 | 黑、灰、橘、奶油、白、棕             |
| 花纹 | 纯色、虎斑、重点色（脸、耳、尾巴深） |
| 白斑 | 无、手套、围兜、奶牛、双色           |
| 眼色 | 蓝、铜、黄绿                         |
| 脸型 | 圆、尖、长                           |

- 品种决定轮廓（T-13：布偶的腮毛和蓬松尾巴、英短的小圆耳和短尾），脸型在品种轮廓上改头形。名册头像、地图上的猫、河畔同伴、撸猫画面、邀请名单用同一套画法（R-15）。
- 每种毛色和它的描线对比度 ≥ 3:1；深色毛（黑、棕）用浅色描线。单测守护。
- 不做自动起名（例如黑色加手套叫"踏雪"），不做每只猫的随机差异。

## 2. 开局：捡到一只流浪猫（T-14）

- 新游戏开场："路边捡到一只流浪猫"，进入捏猫画面：
  - 选品种：田园猫、布偶、英短，每个写明钓鱼特长（田园猫没有专属鱼，写"什么鱼都愿意陪你钓"）；
  - 选五项外观，上方大图实时预览；
  - 🎲 **随机**：一键随机品种和五项，方便测试；
  - 确认后给它起名（T-25，用户 2026-09-30）：同一个起名框，预填第一个推荐名，可以输入或点选推荐名，留空用推荐名；确认后开始游戏，取消回到捏猫画面。
- 这是唯一一次能选品种。之后品种不能改：邀请来的猫是名单模板的品种，生出来的猫由遗传决定（"后续随剧情"）。
- 这只猫仍是 Mochi 的身份（性格、喜欢的鱼、性别，id `mochi`），品种、外观和名字由玩家定（名字见上一条，T-25）。
- 校验：初代猫的性格、喜好、喜欢的鱼、性别仍必须等于模板；**外观不再和模板比**（玩家定、美容院可改），只校验每项是合法选项；初始猫的品种是三种之一，其余初代猫的品种等于模板。
- 田园猫是新品种 `DOMESTIC`。开局选田园猫时，布偶才能引来的锦鲤、英短才能引来的月光鲤要等邀请对应品种的猫才能钓到。节奏与平衡模拟要在三种开局品种下都达标。
- 存档升一版并补拒绝样本；内容版本 +1。

## 3. 猫咪美容院（T-15）

- 新建筑 `CAT_SALON`（猫咪美容院），价格放在 content，由经济模拟定标。
- 建好后点它，选一只伙伴猫，进入同一个捏猫画面，**只改五项外观，不能改品种**；每次改造收费 `RESTYLE_PRICE`（先定 50 金币）。
- 命令 `RESTYLE_CAT { catId, appearance }`，错误码 `NO_SALON`、`INSUFFICIENT_COINS`、`APPEARANCE_UNCHANGED`；外观不影响任何数值。

## 4. 捏猫画面（两处共用）

- 独立的画面模块（纯模型加 DOM 应用），输入"能不能选品种"、确认按钮文字、初始外观，输出确认时的品种和外观或取消。
- 每一项是一排点选按钮，当前选中的高亮；预览随选择实时变化；🎲 随机只改画面上的选择，确认之前不发命令。
- 可及性：只用键盘能走完；每个选项有读屏名；390×844、360×640 放得下，不横向滚动。

## 5. 拆分与验收

- **T-14 PR 1 画法与画面**：五项外观的分层画法、捏猫画面模块（含随机）、一张"所有选项"的对照图。
- **T-14 PR 2 开局**：`DOMESTIC` 品种、外观五项入档、开局捡猫流程、校验与存档升级、三种开局品种的节奏模拟。
- **T-15 美容院**：建筑、命令、入口、收费。
- 测试：每项的颜色和形状只来自自己的选项；对比度；篡改外观为非法值被拒绝，非初始猫的品种被改被拒绝；随机按钮在测试里用注入的随机源，结果确定；存档往返；名册头像和地图画同一套外观；截图 390×844、360×640。
