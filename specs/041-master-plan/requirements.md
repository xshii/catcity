## 1. 产品定位

Cat City 是手机上单手可玩的猫咪小城：玩家建设一座小城，和具体的猫建立长期关系，钓鱼是主要的共同活动。三根支柱（来自 [愿景](../../docs/vision.md)）：

| 支柱  | 含义                       | 玩家的感受目标                     |
| ----- | -------------------------- | ---------------------------------- |
| BUILD | 建造、经营、扩张           | "这座城是我一点点建起来的"         |
| LIVE  | 猫有身份、喜好、住所、家人 | "这些猫真的生活在这里"             |
| BOND  | 交流、照顾、共同经历       | "这只猫认得我，我们一起经历过事情" |

## 2. 用户给出的硬约束

这些约束高于任何具体需求。任何设计与它们冲突时，改设计。

| 编号 | 约束                                                                       | 用户原话                                                           |
| ---- | -------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| C1   | 不疲于生存：必做操作不随猫的数量增长；没有"不照顾就变坏"；没有离线扣减     | "因为有时候会操作好多只猫，不能把玩家搞的疲于生存"                 |
| C2   | 数值不能很快到顶                                                           | "数值系统要做好，不能一下就满了"                                   |
| C3   | 钓鱼只能把心情加到平静上限，开心靠撸猫和送礼                               | 用户在三个方案中选定                                               |
| C4   | 心情与亲密都保留，分工不同                                                 | "心情和亲密度怎么关联还是保留一个即可？" 之后确认两个都保留        |
| C5   | 心情好的猫才能生育；猫可以绝育；有世代（几代目）                           | "心情好猫咪才会生育""可以加一个几代目，就是猫咪可以绝育也可以生育" |
| C6   | 除了认主的猫，还要有 NPC 猫                                                | "catcity 除了认主的猫，还有 npc 猫吧"                              |
| C7   | 手机单屏；提示和卡片不挡水面与钓竿                                         | 多条实机反馈                                                       |
| C8   | 工程：Core 是真相、命令校验、确定性、存档版本化、禁止直推 main、不放宽测试 | [AGENTS.md](../../AGENTS.md)                                       |

## 4. 目标玩家旅程

每个阶段都要有"刚拿到的新东西"和"下一个看得见的目标"。时间是实际游玩时间，来自 [037 数值](../037-cat-life/numbers.md) 和模拟实测。

| 阶段 | 时间           | 玩家在做什么                                 | 刚解锁               | 下一个目标           |
| ---- | -------------- | -------------------------------------------- | -------------------- | -------------------- |
| 初见 | 0–10 分钟      | 认识 Mochi，钓第一条鱼，摸摸它               | 钓鱼、撸猫           | 芦苇河湾；亲密"熟悉" |
| 安家 | 10–40 分钟     | 建公寓、让 Mochi 入住、在旁边建猫咖          | 第一笔营业收入       | 邀请第二只猫         |
| 结伴 | 40 分钟–2 小时 | 邀请新猫，带不同的猫去不同水域，完成猫的心愿 | 月光湖；亲密"信任"   | 第一只小猫           |
| 成家 | 2–6 小时       | 让两只开心的猫生育，给小猫起名，扩建住所     | 二代目；居民楼       | 居民搬进来，猫咖坐满 |
| 小城 | 6–15 小时      | 居民猫住满，猫咖满座，培养三代、四代         | 钓技满级；亲密"家人" | 五代目；图鉴金星     |
| 长线 | 15 小时以上    | 收集纪录、把每只伙伴猫养到"家人"、把城市建满 | —                    | —                    |

### 5.1 收尾（P0）

| 编号 | 需求                                                                          | 验收要点                                                                     |
| ---- | ----------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| R-01 | 在河畔陪玩家钓鱼的猫始终醒着；小城里空闲的猫照旧打盹                          | 瞄准、两竿之间、收获卡显示时，河畔的猫和它的名册头像都不是蜷睡；读屏文字一致 |

## 6. 非功能需求

| 编号 | 需求                   | 如何验证                                                                                           |
| ---- | ---------------------- | -------------------------------------------------------------------------------------------------- |
| N-1  | 负担不随猫数增长（C1） | 模拟：8 伙伴 + 16 居民的世界，30 个游戏日不做任何照顾操作，只要伙伴猫都有住所，没有猫的心情低于 50 |

- 逐只喂食、清洁、看病等维持性操作；饥饿（已删除）。
- 猫的衰老、死亡、走失、出售、放生。
- 隐性基因、突变、稀有度抽取。
- 居民猫的心情、亲密、对话（首版）。
- 旧存档迁移。
