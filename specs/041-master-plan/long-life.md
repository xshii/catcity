# 041 总体规划：能玩很多年（里程碑 M5 长线）

- 配套文档：[需求分析](requirements.md)、[架构设计](design.md)、[美工、界面与交互](ui-design.md)、[任务分解](tasks.md)
- 来源：2026-09-30 用户："怎么做成一个能玩很多年的游戏呢，治愈系的"；"季节和节日也可以以游戏内时间为主，另外这是一个虚拟世界，猫世界的节日可以你来设计"
- 状态：提出。节日的名字、日期、台词都是设计稿，用户可以改。本文件里的数值没有一个经过模拟。
- 前置：M0–M3（撸猫、个体的猫、家庭、居民）。本里程碑不改变它们的规则。

## 1. 目标与原则

目标：玩了 60 小时、把城市建满之后，玩家仍然想回来。靠的不是更多的数值，而是三件事：**世界自己在变、关系留下痕迹、小城长成玩家自己的样子**。

| #   | 原则               | 含义                                                                                                 |
| --- | ------------------ | ---------------------------------------------------------------------------------------------------- |
| L1  | 错过没有损失       | 季节、节日、天气都会再来。任何东西今年没拿到，明年还能拿到。没有"限时绝版"                           |
| L2  | 以游戏内时间为准   | 日历由 `world.minute` 推导，不读现实日期。玩家调快时钟，季节也跟着快                                 |
| L3  | 只增不减           | 季节和天气只带来新的东西（鱼、景色、猫的举动），不让任何已有的事变难                                 |
| L4  | 不新增必做操作     | 节日活动都是现有操作的变奏（钓鱼、送鱼、摸猫、在地图上点一下），没有新的日常                         |
| L5  | 推导优先           | 日历、天气、节日、猫的生日都由种子和时间推导，不入档。入档的只有玩家得到的东西（回忆、纪念品、摆件） |
| L6  | 每次打开有一点不同 | 同一个小城，今天和昨天看起来不完全一样                                                               |

和硬约束的关系：L1、L3、L4 是 C1（不疲于生存）在长线内容上的具体化。

## 2. 猫历

### 2.1 结构

| 单位 | 长度          | 实际游玩时间（1× / 4×）  |
| ---- | ------------- | ------------------------ |
| 一天 | 1440 游戏分钟 | 24 分钟 / 6 分钟         |
| 一季 | 28 天         | 约 11 小时 / 约 2.8 小时 |
| 一年 | 4 季 = 112 天 | 约 45 小时 / 约 11 小时  |

选 28 天一季的理由：一季跨越几次游玩，玩家能注意到"变天了"；一年约等于把城市建满的时间，所以第二年开始时玩家正好进入长线阶段。

新游戏从**萌芽季第 1 天 07:00** 开始（和现在的 07:00 开局一致）。

```ts
// src/content/calendar.ts：数值；src/core/calendar.ts：纯函数
calendarOf(minute): { year: number; season: Season; day: number; dayOfYear: number }
// year 从 1 起；day 1–28；dayOfYear 1–112
```

顶栏的时间从"第 1 天 · 07:00"改为"萌芽季 1 日 · 07:00"，点一下展开小日历（见第 8 节）。年份写作"小城第 2 年"。

### 2.2 四季

| 季节 | 名字   | 地图的样子                 | 水边的样子             | 猫的举动                   |
| ---- | ------ | -------------------------- | ---------------------- | -------------------------- |
| 春   | 萌芽季 | 嫩绿的草地，零星小花       | 水色浅，岸边有新芽     | 伸懒腰、追蝴蝶             |
| 夏   | 长日季 | 深绿，树影浓，白天更长     | 荷叶铺开，水面反光强   | 躲在树荫下、趴着吐舌       |
| 秋   | 金叶季 | 草地泛黄，落叶飘过         | 水色深，岸边芦花       | 扑落叶、囤着不肯走的鱼     |
| 冬   | 暖炉季 | 薄雪覆盖，屋顶白边，窗更亮 | 岸边结薄冰，水面有雾气 | 缩成团、靠着烟囱、呼出白气 |

白天的长度随季节变化（只影响光照，不影响规则）：长日季天亮得早、黑得晚；暖炉季相反。由 `cityLight(minute)` 读日历得到。

季节对规则的影响只有一处：**每个季节有当季的鱼**（第 5 节）。步行速度、收入、体力、心情都不随季节变。

## 3. 天气

每天一种天气，由 `streamSeed(seed, 'weather', 第几天)` 决定，不入档。

| 天气 | 出现的季节             | 画面                         | 对玩法的影响（全是好处）               |
| ---- | ---------------------- | ---------------------------- | -------------------------------------- |
| 晴   | 四季                   | 现在的样子                   | 无                                     |
| 多云 | 四季                   | 光线柔和，影子淡             | 无                                     |
| 小雨 | 春夏秋                 | 雨丝、水面涟漪、猫躲在屋檐下 | 等鱼咬钩的时间缩短 20%                 |
| 雾   | 秋冬的清晨             | 远处变淡                     | 月光湖和河湾的大鱼影更常见             |
| 雪   | 冬                     | 飘雪、地上积白、脚印         | 猫在自己家旁边时心情回落点 +2          |
| 彩虹 | 雨后的那一天，概率很低 | 天边一道虹                   | 这一天钓到的第一条鱼在相册里多一条记录 |

各季的天气比例在 content 里配置。连续下雨不超过 2 天（同一个推导函数里保证）。天气不会让任何事变难：雨天走路不变慢，雪天不挡路。

## 4. 猫世界的节日

节日由日历推导。每个节日有三样东西：**小城的样子**、**一件可以做的小事**、**一件纪念**。小事都是已有操作的变奏；纪念每年都能得到，第一次得到时进相册。

节日最短 2 天。节日前一天，顶栏的日期旁出现一个小灯笼，居民的招呼语会提到"明天就是晒垫节了"。

### 4.1 节日一览

| 季节   | 日期     | 节日   | 一句话                                 |
| ------ | -------- | ------ | -------------------------------------- |
| 萌芽季 | 7–8 日   | 晒垫节 | 入春第一次晒太阳，全城的猫把垫子搬出来 |
| 萌芽季 | 21–22 日 | 猫草祭 | 猫草冒芽的日子，家家门口摆一盆         |
| 长日季 | 14–15 日 | 渔火夜 | 一年里最短的夜，水面漂满小灯           |
| 长日季 | 25–26 日 | 纸箱节 | 没有哪只猫拒绝得了纸箱                 |
| 金叶季 | 10–12 日 | 丰鱼宴 | 把一年的好鱼摆上长桌，全城一起吃       |
| 金叶季 | 23–24 日 | 毛线节 | 入冬前织围巾，毛线球滚得到处都是       |
| 暖炉季 | 3–4 日   | 初雪日 | 第一场雪，脚印从每个家门口出发         |
| 暖炉季 | 27–28 日 | 团圆夜 | 一年的最后两天，一家几代挤在一个暖炉旁 |

另有两个不在固定日期的日子：

| 日子     | 什么时候           | 一句话                                   |
| -------- | ------------------ | ---------------------------------------- |
| 建城日   | 每年萌芽季 1 日    | 小城又长了一岁                           |
| 猫的生日 | 每只猫自己的那一天 | 出生的猫是出生那天；初代猫是来到小城那天 |

### 4.2 每个节日的设计

**晒垫节（萌芽季 7–8 日）**

- 小城：每座住所门口铺着一张花垫子，猫躺在上面。阳光比平时暖一点。
- 小事：摸摸躺在垫子上的猫（就是撸猫）。这两天撸猫的第一局，猫会翻出肚皮，不管它平时喜不喜欢被摸肚子。
- 纪念：摆件"花垫子"（可以摆在自己的地上）。相册："和 Mochi 一起晒了第一个春天的太阳"。
- 猫说："太阳把垫子晒得软软的……你也躺一会儿。"

**猫草祭（萌芽季 21–22 日）**

- 小城：每家门口一盆猫草，居民在给它浇水。路边冒出一丛丛嫩草。
- 小事：地图上随机几处草地长出了野猫草（由种子决定位置），点一下采下来，送给任意一只猫（走送礼的通道，算一次送礼）。
- 纪念：摆件"一盆猫草"。相册："Pepper 第一次尝到新鲜猫草，打了三个喷嚏"。
- 猫说："新长出来的最嫩。分你一根？……哦，你不吃这个。"

**渔火夜（长日季 14–15 日）**

- 小城：天黑后每处水面漂着小灯，岸边挂着灯笼。这两天夜里不会全黑。
- 小事：夜里钓鱼。水面的小灯会聚在鱼影上方，所以鱼影比平时好找。夜里钓到的每条鱼，岸边多亮一盏灯（只是画面）。
- 纪念：摆件"小灯笼"。相册："渔火夜，和团子在月光湖钓到了一条 62 厘米的锦鲤"。
- 猫说："灯飘到哪里，鱼就在哪里。嘘，小点声。"

**纸箱节（长日季 25–26 日）**

- 小城：街上到处是纸箱。居民和没在忙的伙伴猫钻在箱子里，只露出耳朵或尾巴。
- 小事：捉迷藏。点露出耳朵的纸箱，里面的猫探出头来打招呼；找到自己的伙伴猫时它心情 +3（每只猫一次）。找不找都行。
- 纪念：摆件"刚刚好的纸箱"。相册："纸箱节，在猫咖后面的箱子里找到了年糕"。
- 猫说："……你怎么找到的？这个箱子明明刚刚好。"

**丰鱼宴（金叶季 10–12 日）**

- 小城：起始路口摆出一张长桌。玩家每送出一条鱼（送给猫，或者直接放到长桌上），桌上就多一盘。居民围着桌子坐。
- 小事：把鱼放到长桌上（新的一个去处，和卖鱼、送鱼并列，只在这三天有）。放上去的鱼不给金币，全城的猫心情 +1（每天最多算 5 条）。
- 纪念：摆件"小长桌"。相册："丰鱼宴的长桌上摆了 12 盘鱼，其中 7 盘是我钓的"。
- 猫说："这条是你钓的吧？我认得，上面有你的味道。"

**毛线节（金叶季 23–24 日）**

- 小城：屋檐下挂着织到一半的围巾，毛线球在路上滚。猫追着毛线球跑。
- 小事：点滚动的毛线球，把它拨给最近的一只猫，它会玩一会儿。节日结束时，亲密到"熟悉"以上的伙伴猫各自戴上一条围巾，戴到暖炉季结束。
- 纪念：摆件"毛线球篮子"。相册："豆包织了一条围巾，颜色是它自己挑的"。
- 猫说："不是我弄乱的。是它自己滚的。"

**初雪日（暖炉季 3–4 日）**

- 小城：这两天一定下雪。地上留下每只猫走过的脚印，过一会儿被雪盖住。
- 小事：带一只猫在雪地里走一段（就是派它步行）。它走过的脚印会留得久一点，拼成一条路。
- 纪念：摆件"小雪猫"。相册："初雪日，和 Mochi 从家门口一直走到了池塘"。
- 猫说："爪子好凉！……再走一会儿。"

**团圆夜（暖炉季 27–28 日）**

- 小城：每座住所的窗都亮着。同一家的猫（父母、子女、兄弟姐妹）聚到其中一只的家旁边。
- 小事：点亮着窗的住所，看到这一家围着暖炉的样子。没有要做的事。
- 纪念：相册里自动多一张**全家福**：这一年小城里所有的伙伴猫，按家庭站在一起，写着"小城第 N 年"。每年一张，越攒越多。这是整个长线设计里最重要的一件纪念。
- 猫说："今年也一起过。明年也是。"

**建城日（每年萌芽季 1 日）**

- 小城：起始路口立着一块小牌子"小城第 N 年"。
- 纪念：相册首页的年份更新，并写下这一年的几件事（新来了几只猫、出生了几只、钓到的最大的鱼、建了什么）。由世界的事实统计得出。

**猫的生日**

- 那一天这只猫头上有一顶小帽子。送它喜欢的鱼，它会说一句生日专属的话。
- 相册："团子 2 岁了"。不送也没关系，帽子照戴。

### 4.3 节日的规则边界

- 节日期间的加成只有正向的，而且都很小（心情 +1 到 +3）。不给金币、钓技经验和亲密点数的额外倍率，避免玩家为了效率去等节日。
- 节日的小事每年可以做，纪念每年可以拿。已经有的摆件再拿一次会多一件，可以摆多个。
- 节日不弹窗打断玩家。开始时顶栏出现节日名，居民和猫的话会变，小城换样子。
- 一个节日正在进行时推进时钟跳过了它：没有任何提示说"你错过了"。

## 5. 当季的鱼

每处水域每季有一种当季鱼，只在那个季节出现。一共 16 种，分批加入，首批每季 1 种（放在已开放最早的两处水域），让图鉴在很长时间里一直有空位。

| 季节   | 水域       | 鱼（设计稿） | 星级 | 线索             |
| ------ | ---------- | ------------ | ---- | ---------------- |
| 萌芽季 | 家门口池塘 | 桃花鱼       | 1    | 雨天，向左抛     |
| 长日季 | 芦苇河湾   | 荷叶鲤       | 2    | 清晨，蚯蚓       |
| 金叶季 | 潮汐海岸   | 秋刀鱼       | 3    | 傍晚，虾饵，抛远 |
| 暖炉季 | 月光湖     | 冰纹鳟       | 4    | 雾天或雪天，虾饵 |

- 图鉴里当季鱼有季节标记；不在季节时条目写"萌芽季再来"。
- 当季鱼可以成为猫的心愿（只在当季）。
- 钓技经验照常给。加入前要重跑节奏模拟：图鉴种类影响水域解锁条件（"发现 N 种鱼"），当季鱼不计入解锁条件，避免新玩家因为季节不对而卡住。

## 6. 回忆相册

现在每只猫只记两件事（第一次钓到鱼、最近一次送鱼）。扩成一本会越来越厚的相册。

### 6.1 记什么

| 类型   | 什么时候记                                                 | 每只猫记几次 |
| ------ | ---------------------------------------------------------- | ------------ |
| 相遇   | 邀请来、出生                                               | 1            |
| 第一次 | 第一次一起钓到鱼、第一次被摸、第一次收到礼物、第一次住进家 | 各 1         |
| 成长   | 亲密每升一级；幼猫长大；生日                               | 每次         |
| 家庭   | 生了小猫；当了祖父母                                       | 每次         |
| 纪录   | 钓到个人最长的某种鱼；图鉴金星                             | 每次刷新     |
| 心愿   | 心愿实现                                                   | 每次         |
| 节日   | 每个节日第一次参加；每年的全家福                           | 每年         |
| 天气   | 彩虹天的第一条鱼                                           | 每次         |

每条回忆是一个事实：类型、时间、涉及的猫、相关的东西（鱼种、体长、地点）。**文字不入档**，显示时由事实生成，所以以后可以改写法、换语言，接入 AI 对话后也可以让猫用自己的话重讲。

### 6.2 容量

- 每只猫最多 200 条，全城的回忆（全家福、建城日）最多 200 条。
- 满了以后，"纪录"类里被更新的旧纪录先合并（只留最新的）；"第一次""相遇""家庭""全家福"永远不删。
- 按每游戏年 30 条左右估算，一只猫能记 6 年以上。

### 6.3 怎么用

- 猫详情里新增"回忆"分区，按年和季节分组，最新的在上面。
- 对话里猫会提起旧事："去年渔火夜，我们在月光湖钓到那条锦鲤。"规则对话从相册里按日期挑一条去年同一季的回忆。
- 玩家重新打开游戏、距上次游玩超过一个游戏季时，第一只被选中的猫说一句和最近的回忆有关的话。不说"你好久没来了"。

## 7. 摆件

不影响任何数值的装饰，让小城长成玩家自己的样子，也给金币一个花不完的去处。

| 项目     | 规则                                                             |
| -------- | ---------------------------------------------------------------- |
| 放在哪   | 自己的地上，没有建筑和道路的格子。一格一件                       |
| 挡不挡路 | 不挡。猫可以走过，站在摆件旁边时偶尔会和它互动（闻花、跳上长椅） |
| 来源     | 商店用金币买（花坛、长椅、路灯、小池、栅栏、风铃）；节日的纪念   |
| 价格     | 固定价格，不随数量上涨（摆件不产生收益，不需要防刷）             |
| 收回     | 随时收回背包，再摆到别处，不花钱                                 |
| 季节     | 摆件随季节换样子：花坛春天开花、冬天盖雪                         |

摆件和建筑共用"点格子 → 操作卡"的流程，操作卡里多一个"摆件"分组。

### 8.2 季节切换

换季的那一刻（第 28 日到次日 0 点）地图用 2 秒的渐变换色，提示条写一句："金叶季到了。"不出庆祝卡。

### 8.3 节日中的小城

## 9. 架构

### 9.1 新模块

```
src/content/calendar.ts     季节、节日表、天气比例、白天长度
src/content/keepsakes.ts    摆件与纪念品的定义
src/content/fishing/        当季鱼（带 season 字段）
src/core/calendar.ts        calendarOf、weatherOf、festivalOf、birthdayOf（全是纯函数）
src/core/album.ts           记一条回忆、容量整理
src/core/decor.ts           摆、收、买摆件的命令
src/view/art/seasons.ts     四季与天气的调色和粒子
src/view/art/festivals.ts   节日装饰的绘制
src/view/cats/album.ts      相册画面
src/view/shell/calendar.ts  顶栏日期与小日历
```

### 9.2 入档与推导

| 东西                                       | 入档     | 推导自                                                                 |
| ------------------------------------------ | -------- | ---------------------------------------------------------------------- |
| 日历、季节、节日                           | 否       | `world.minute`                                                         |
| 天气                                       | 否       | 种子 + 第几天                                                          |
| 野猫草、纸箱、毛线球的位置                 | 否       | 种子 + 年 + 节日                                                       |
| 节日里"已经做过"的事（采过的草、找到的猫） | 是，最小 | `world.festival: { id, year, done: string[] } \| null`，节日结束后清空 |
| 回忆                                       | 是       | —                                                                      |
| 摆件（位置、种类）和背包                   | 是       | —                                                                      |
| 猫的生日                                   | 否       | `bornMinute`，初代猫用来到小城的那一天（要新存一个 `joinedMinute`）    |
| 围巾                                       | 否       | 季节 + 去年毛线节时的亲密等级（要存 `scarfYear`）                      |

存档版本 +1（回忆、摆件、`world.festival`、`joinedMinute`、`scarfYear` 一次加齐）。

### 9.3 规则放在哪

- 季节和天气对钓鱼的影响，在 `FISH_BEGIN` 开一竿时读日历并记进这一竿的状态（和 `happy`、`talent` 一样），之后这一竿不再随时间变化。这样存档续玩和回放的结果不变。
- 节日的小事都是命令：`PICK_FESTIVAL_ITEM { id }`（采草、找到纸箱里的猫、拨毛线球）、`OFFER_FISH { fishId }`（丰鱼宴）。Core 校验现在是不是那个节日、这件事是不是还没做过。
- 回忆由 Core 在对应命令结算时写入，不由画面写。

### 9.4 时间推进的等价性

`simulate` 逐分钟推进，节日开始和结束、换季、生日都发生在确定的分钟。一次推进 30 天和分 30 次推进必须得到相同的世界，包括回忆的顺序。全家福在团圆夜第二天的 0 点生成。

## 10. 任务分解

都依赖 M1（个体的猫）。T-64、T-65 还依赖 M2（家庭）。每个任务遵守 [tasks.md 的执行规程](tasks.md#执行规程)。

| 任务 | 内容                                                                       | 依赖             | 存档              |
| ---- | -------------------------------------------------------------------------- | ---------------- | ----------------- |
| T-60 | 猫历：`calendarOf`、顶栏日期、小日历                                       | —                | 不变              |
| T-61 | 四季的画面：地图与水面换色、白天长度、换季渐变                             | T-60             | 不变              |
| T-62 | 天气：推导、画面、三条正向影响                                             | T-60             | 这一竿记天气，+1  |
| T-63 | 回忆相册 Core：事实结构、写入点、容量；把现有的首钓与赠鱼记忆并进来        | —                | +1                |
| T-64 | 相册画面；对话引用旧回忆                                                   | T-63、T-12       | 不变              |
| T-65 | 建城日、生日、全家福                                                       | T-60、T-63、T-22 | 与 T-63 同版或 +1 |
| T-66 | 摆件：命令、商店、操作卡、随季节换样子                                     | T-61             | +1                |
| T-67 | 节日框架：`festivalOf`、前一天的灯笼、居民和猫的节日台词、`world.festival` | T-60、T-32       | +1                |
| T-68 | 第一批节日：晒垫节、渔火夜、丰鱼宴、团圆夜（每季一个）                     | T-67、T-63、T-66 | 不变              |
| T-69 | 第二批节日：猫草祭、纸箱节、毛线节、初雪日                                 | T-68             | 不变              |
| T-70 | 当季的鱼（首批 4 种）与平衡、节奏模拟                                      | T-60             | 内容 +1           |

建议的顺序：T-60 → T-63 → T-61 → T-64 → T-65 → T-62 → T-66 → T-67 → T-68 → T-70 → T-69。先做日历和相册，是因为它们最便宜、情感价值最高，而且后面的每一项都往相册里写东西。

每个任务的验收除了规程里的通用要求，还有：

- **L1 的模拟**：把时钟一次推进 3 个游戏年，不做任何操作。断言：没有猫的心情低于 50；没有任何东西被扣减；每个节日的纪念在第 2、第 3 年仍然可以得到。
- **等价性**：一次推进一年和逐日推进一年，世界完全相同。
- **四季截图**：同一个小城在四个季节、三种天气下各一张，390×844。
