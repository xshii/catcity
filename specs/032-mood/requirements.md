# 032 心情系统

- 状态：进行中
- 来源：2026-09-29 用户："我觉得还可以加一个心情系统"；确认方向：心情有涨有落、温和奖励、显示在猫咪面板，在全屏布局（031）之后做。

## 现状

猫的 `mood`（0–100，新猫 70）只在钓到鱼、收到礼物时上涨，从不下降，界面只显示"心情不错 / 想安静一会儿"。

## 规则（Core，数值在 `content/mood.ts`）

| 变化     | 时机                                     | 数值                 |
| -------- | ---------------------------------------- | -------------------- |
| 回归平静 | 每整点，向 60 靠拢                       | 每小时 ±2，不越过 60 |
| 住在家旁 | 每整点，猫在自己公寓旁                   | 额外 +1              |
| 聊天     | 与关系增长同一冷却（每游戏小时最多一次） | +2                   |
| 钓到鱼   | 现有                                     | +3                   |
| 送礼     | 现有；最爱的鱼更多                       | +3 / +8              |
| 鱼跑了   | 这一竿以脱钩或超时结束（主动收竿不算）   | −3                   |
| 累坏了   | 步行中体力降到 0                         | −5                   |

心情档位：≥80 开心、50–79 平静、30–49 有点闷、<30 低落。

## 效果（只奖励，不惩罚）

- 开心的猫开一竿时，这一竿记下"开心"：体感遛鱼的圈半径 +1、提竿窗口 +2 tick；按钮版绿区宽 +4。
- 规则对话按档位换语气（低落时更安静、开心时更主动），不改变事实记忆。
- 低落不减收益、不禁止行动。

## 界面

- 「猫咪」面板名册卡与「说说话」头部显示档位（表情 + 文字），开心时提示"开心：遛鱼圈更大"。
- 心情变化不弹窗；钓鱼结果与送礼提示里带一句变化（如"Mochi 更开心了"）。

## 存档

- 进行中的一竿新增 `happy` 字段，saveVersion 升一版；旧档拒绝并保留原数据。

## 验收

- 单测：每条变化与边界（0/100 夹紧、整点漂移不越过 60、分块推进等价、被拒命令不改心情）。
- 模拟：30 天随机命令下心情始终在界内；不变量测试覆盖心情变化来源。
- 平衡：开心加成下老练玩家的高星上鱼率提升有限（≤ 设定上限），新手仍钓不到 4–5★。
- E2E：猫咪面板显示档位（一条冒烟）。
