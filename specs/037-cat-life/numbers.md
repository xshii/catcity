# 037 数值设计：不要太快到顶

- 状态：提出（等待用户确认；确认后数值进入 `src/content/`，由模拟测试守护）
- 来源：2026-09-29 用户："请你仔细设计一下这个数值系统不要太快速到顶"
- 需求见 [requirements.md](requirements.md)。本文件中的数值取代 requirements.md 第 4–6、9 节里的建议数值。

## 1. 为什么现在会很快到顶

| 成长量   | 现在的规则                             | 到顶需要                                            |
| -------- | -------------------------------------- | --------------------------------------------------- |
| 钓技     | 每级固定 40 经验，10 级封顶            | 360 经验，约 25 条鱼，约 25 分钟                    |
| 水域解锁 | 最高要求钓技 4、4 种鱼                 | 约 10 条鱼                                          |
| 亲密     | 每游戏小时最多 +1，上限 100            | 4× 速度下 1 游戏小时 = 15 秒，100 点约 25 分钟      |
| 金币     | 猫咖每游戏小时 +10，数量不限，无需客人 | 4× 速度下每家每分钟 40 金币，7.5 分钟回本，指数增长 |

两个根本原因：

1. **成长用游戏时钟限速，而游戏时钟可以调到 4×**，所以"每小时一次"的上限实际是每 15 秒一次。
2. **曲线是线性的，收益没有递减**（钓技每级等价，猫咖每家等价）。

## 2. 设计方法

- M1 **用实际游玩时间定目标**，再反推数值。基准节奏：钓鱼约每分钟 1 条（小游戏内固定 1×）；城市按 4× 估算。
- M2 **成长靠付出，不靠等待**：亲密和钓技只从需要实际操作的行为获得（钓到鱼、撸猫、送鱼），不从"时间到了点一下"获得。
- M3 **曲线递增**：越往后每级越贵；每个成长量的前 10% 要在第一次游玩（30 分钟）里拿到，让玩家尽早看到变化。
- M4 **收益递减**：同类来源重复使用时递减（心情高位减半、猫咖客人有限、建筑越建越贵）。
- M5 **每个数值都有模拟测试**断言"到顶所需的操作次数"落在目标区间内；改数值必须同时改目标。

## 3. 节奏目标

| 里程碑                         | 目标实际游玩时间 |
| ------------------------------ | ---------------- |
| 第一条鱼、第一次让猫开心       | 5 分钟内         |
| 芦苇河湾；亲密"熟悉"           | 10–15 分钟       |
| 潮汐海岸                       | 30–40 分钟       |
| 月光湖；亲密"信任"；第一只小猫 | 1.5–2 小时       |
| 第一只猫亲密"亲密"             | 4–5 小时         |
| 钓技满级                       | 12–15 小时       |
| 第一只猫亲密"家人"             | 12–15 小时       |
| 五代目                         | 15 小时以上      |
| 8 只伙伴猫全部"家人"、城市住满 | 60 小时以上      |

## 4. 钓技

经验来源不变：钓到鱼 `10 + 5 × 星级`；开心的猫 ×1.5（向下取整）。

升到第 n 级的累计经验：`30 × (n − 1) × n × (n + 1) / 3`（原为 25；节奏模拟中熟练玩家 42 条鱼就到月光湖，见 [038](../038-growth-numbers/requirements.md)）。

| 等级 | 累计经验 | 约合条数（均 20 经验） | 解锁                    |
| ---- | -------- | ---------------------- | ----------------------- |
| 2    | 60       | 5（池塘鱼均 12 经验）  | 芦苇河湾（另需 2 种鱼） |
| 3    | 240      | 14                     | 潮汐海岸（另需 3 种鱼） |
| 4    | 600      | 32                     | —                       |
| 5    | 1200     | 60                     | 月光湖（另需 4 种鱼）   |
| 6    | 2100     | 105                    |                         |
| 7    | 3360     | 170                    |                         |
| 8    | 5040     | 250                    |                         |
| 9    | 7200     | 360                    |                         |
| 10   | 9900     | 约 300–430（模拟）     | 满级                    |

- 月光湖的等级要求从 4 改为 5。
- 钓技每级的效果不变（绿区宽 +2）。
- 后期主要在月光湖和海岸钓 2–5★ 的鱼，均值约 25–30 经验，约三分之一的竿有开心加成；节奏模拟中满级是 294 条鱼（熟练）到 432 条鱼（新手）。

## 5. 亲密

改为"亲密点数"，不再使用每小时一次的时钟上限。上限从 100 提高到 2000（高于"家人"的 1500）（存档字段范围变化）。

| 来源                  | 点数        | 限制                     |
| --------------------- | ----------- | ------------------------ |
| 一起钓到鱼            | +2          | 无（每条鱼都要实际操作） |
| 送最喜欢的鱼 / 其他鱼 | +3 / +1     | 消耗一条鱼               |
| 撸猫一局（表现好）    | +2          | 每只猫每游戏日前 3 局    |
| 聊天                  | +1          | 每只猫每游戏日 1 次      |
| 猫开心时              | 以上各项 +1 | —                        |

| 等级 | 累计点数 | 专心陪一只猫约需 |
| ---- | -------- | ---------------- |
| 初识 | 0        | —                |
| 熟悉 | 25       | 10–15 分钟       |
| 信任 | 150      | 1–1.5 小时       |
| 亲密 | 500      | 4–5 小时         |
| 家人 | 1500     | 12–15 小时       |

- 撸猫和聊天的每日次数只限制"免费来源"；钓鱼和送鱼不限，所以想肝可以肝。
- 每级回落点 +3 不变（家人时 72）。

## 6. 心情

范围 0–100，回落点 60（受亲密与住所影响），开心线 80。

| 规则                  | 数值                                          |
| --------------------- | --------------------------------------------- |
| 整点回归              | 80 以下每小时 2；**80 以上每小时 4**          |
| 高位递减              | 心情 ≥80 时，所有加心情的来源减半（至少 1）   |
| 钓到鱼 / 鱼跑了       | +5 / −3                                       |
| 撸猫一局              | +2～+8；每只猫每游戏小时前 2 局完整，之后减半 |
| 送最喜欢的鱼 / 其他鱼 | +8 / +3                                       |

目标（由模拟验证）：

- 从平静（60）到开心（80）：撸猫 2–3 局，约 1 分钟的主动操作。
- 只钓鱼不撸猫：熟练玩家约 30–50% 的竿是开心状态。这个目标按每游戏小时一竿计；抛得更快占比更高（见 038 的节奏模拟）。钓到鱼原为 +3，每小时一竿时没有一竿开心，所以改为 +5。
- 钓鱼间隙撸猫：约 70–85%。
- 不可能做到 100% 开心，所以经验 ×1.5 永远是"争取来的"，不是常态。

## 7. 金币与建设

| 项目     | 现在              | 改为                                                                                  |
| -------- | ----------------- | ------------------------------------------------------------------------------------- |
| 猫咖收入 | 每家每游戏小时 10 | 每位客人每游戏小时 2；每家最多 5 位客人；每只猫只算作一家的客人（最近的一家，3 格内） |
| 猫咖价格 | 300               | 第 n 家 `300 × 1.5^(n−1)`（300、450、675、1010…），取整到 5                           |
| 公寓价格 | 250               | 第 n 座 `250 × 1.4^(n−1)`（250、350、490、685…），取整到 5                            |
| 土地     | 50                | `50 + 25 × 到起始路口的格距`（超出起始城区的部分）                                    |
| 鱼价     | 8–100             | 不变                                                                                  |

- 总收入上限 = 2 × 猫的总数 / 游戏小时。24 只猫（8 伙伴 + 16 居民）住满时每游戏小时 48。
- 城市住满需要 12 座公寓（总价约 3.5 万）和 5 家猫咖（约 4000），加土地与道路。目标：60 小时以上。
- 钓鱼收入（每分钟约 15–40 金币）在前期是主要来源，猫咖是中后期的稳定补充，两者量级接近，不让任何一个取代另一个。

## 8. 生育与世代

| 项目         | 数值                  |
| ------------ | --------------------- |
| 父母亲密要求 | 各自"信任"（150 点）  |
| 父母心情要求 | 各自 ≥80              |
| 父母冷却     | 3 个游戏日            |
| 幼猫期       | 2 个游戏日            |
| 世代天赋     | 每代最多 +1，五代封顶 |

到五代目最少需要 4 次生育。每次的瓶颈是把新成年的猫养到"信任"（1–1.5 小时），所以五代目至少 5–6 小时的专注培养，通常 15 小时以上。冷却与幼猫期使用游戏时钟，只是防止连点，不是主要限速。
