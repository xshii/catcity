# 030 设计：体感钓鱼（手机即鱼竿）

按钮版本**冻结**：保持现有流程（准备 → 按住蓄力 → 绿区提竿 → 张力遛鱼），不做改动。本设计只针对开启体感后的流程。

## 市面对照（2026-09 检索）

| 已有做法                       | 例子                                                                                         | 与本设计的关系                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 挥动设备抛竿，速度决定距离     | Fishing Master（手机）、Reel It In（手机原型）、Wii Fishing Resort、Switch Legendary Fishing | 抛竿沿用这一成熟手感，不是差异点                         |
| 旋转手柄收线 / 跟随拉力转竿    | Legendary Fishing、Wii Fishing Resort                                                        | 不采用：手机上旋转收线易疲劳、易误触                     |
| 倾斜手机操控鱼钩               | Ridiculous Fishing                                                                           | 相近的倾斜操控，但用于躲鱼/收集                          |
| 把控制条压在游动的鱼上累计进度 | Stardew Valley（一维、按键）                                                                 | 遛鱼的核心循环同源，本设计改为**二维 + 体感 + 收缩鱼圈** |
| 倾斜操控下沉的鱼钩抓鱼/躲鱼    | Ninja Fishing、Ridiculous Fishing（手游）                                                    | 倾斜操控相近；遛鱼以点击或无对抗为主                     |
| 挥动手机抛竿、接鱼             | Fishy Business（手游）                                                                       | 抛竿手感相近                                             |

差异点（检索范围内的手游未见同类遛鱼）：**倾斜竿尖在二维水面追一个游动、呼吸收缩的鱼圈**，加上"假咬口 → 真咬口'！'→ 反射上扬"的判断。单项有先例，组合少见。

## 默认模式（2026-09-28 确认）

- 支持体感的手机**默认使用体感版本**（替换现有文档中"体感默认关闭"）。
- 首次进入钓点显示一张卡片"开启体感钓鱼（倾斜瞄准、甩动抛竿）"，点一下即请求权限（iOS 必须由点击触发）；旁边提供"改用按钮"。
- 无需权限的浏览器（多数 Android）收到首个有效读数即启用，不弹卡片。
- 拒绝权限、非 HTTPS、无陀螺仪：自动使用冻结的按钮版本。
- "钓具 → 设置"可随时切换，选择按设备记住（View 本地偏好，不入存档）。

## 握姿、视角与校准（2026-09-28 改版确认）

- 画面改为第一人称：从栈桥望向水面，远处对岸在地平线上，水面近宽远窄；四处水域（池塘、芦苇河、月光湖、海岸）各有景物。几何在 `view/art/water-view.ts`，河面美术、点水瞄准与遛鱼平面共用。
- 竖握手机、屏幕对着自己、面向水面。进入瞄准时自动把当前握姿记为零点。
- **左右倾斜**：抛投方向。**慢慢俯仰**：力度（零点为 50，向后仰加力、向前俯减力，±25° 为 0–100）；落点标记随力度远近移动，力度条标出 55–80 的精准区间。
- **快速下甩**：抛竿。俯仰角速度超过起始速度（80°/s）时记下起点，超过下甩阈值（250°/s）即抛出，力度取起点前 0.1 秒那一刻，下甩本身不改变力度；每次下甩只抛一次，抛出后短时间内的回弹不算提竿。
- **一键校准**：点"校准甩竿"后向下快甩两次。取转速最大的轴；每次下甩的方向取它的第一个强峰值（回弹在后面，不会被误认）；两次方向必须一致，否则请玩家重来。下甩阈值取较弱那次的 50%（限 120–400°/s），结果按设备存本地，读取时校验范围。校准中离开水边或开始一竿会取消校准。
- 默认下甩方向为 beta 减小（按 W3C 朝向定义：手机竖直时顶端向外倾，beta 变小）；实机方向不同时用校准纠正。

## 一竿的流程

| 阶段   | 玩家动作                                                                               | 反馈                                                                   | 判定（Core）                                                           |
| ------ | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 1 瞄准 | 左右倾斜定方向，慢慢俯仰定力度                                                         | 第一人称水面上的落点标记随方向左右、随力度远近移动；力度条标出精准区间 | 方向 −45°～45°、力度 0–100，下甩前一刻锁定                             |
| 2 甩竿 | **快速下甩**竿尖                                                                       | 出竿轻震                                                               | View 报下甩前的力度；55–80% 为精准抛投。此刻才扣体力和鱼饵             |
| 3 等待 | 拿稳即可                                                                               | 浮漂漂动；**假咬口**：轻点头 + 轻震                                    | 假咬口次数由种子和星级决定                                             |
| 4 咬钩 | 看到 **"！"** + 强震，**快速上扬**（竿尖向上的角速度超过阈值）                         | 反应越快判定越好：完美 / 成功                                          | 窗口按星级；假咬口时上扬 = 惊鱼：真咬口推迟、窗口变短一档；超时脱钩    |
| 5 遛鱼 | 先 1.5 秒适应，再倾斜手机移动**竿尖点**（roll → 左右，pitch → 前后），追住**金边鱼圈** | 点在圈内：圈变绿；圈外：变红；冲刺前鱼圈泛起涟漪                       | 圈内累计 +1/tick，圈外 −2/tick；鱼圈随进度收缩、呼吸；鱼按随机游走移动 |
| 6 出水 | 进度满时鱼跃出水面                                                                     | 结果卡、鱼的大小                                                       | 与现有结算一致；遛鱼超时 = 脱钩                                        |

## 难度规格（2026-09-28 确认；数值在 `content/fishing/motion.ts`，由平衡测试守护）

设计原则：新颖在输入与手感，门槛在"读鱼"。难度来自鱼的不可预测性（转向、变速、冲刺）相对鱼圈大小，而不是单纯的速度；高星鱼要老练才能钓到。

| 星级                          | 0       | 1      | 2       | 3       | 4       | 5       |
| ----------------------------- | ------- | ------ | ------- | ------- | ------- | ------- |
| 提竿窗口（秒）                | 0.9     | 0.8    | 0.7     | 0.6     | 0.5     | 0.45    |
| 假咬口次数                    | 0–1     | 1      | 1–2     | 2       | 2–3     | 3       |
| 巡游速度（单位/秒，水面 100） | 12      | 18     | 24      | 30      | 34      | 38      |
| 直游时长（秒）                | 1.5–2.5 | 1.2–2  | 0.9–1.6 | 0.7–1.3 | 0.5–1   | 0.4–0.8 |
| 转向角（左右随机）            | 0–60°   | 20–90° | 30–110° | 45–135° | 55–150° | 70–160° |
| 每段变速                      | ±10%    | ±15%   | ±20%    | ±25%    | ±30%    | ±35%    |
| 休息段概率（0.3 倍速）        | 30%     | 24%    | 18%     | 12%     | 6%      | 0       |
| 冲刺（每秒概率）              | 0       | 5%     | 8%      | 12%     | 15%     | 20%     |
| 鱼圈半径 起始 → 最小          | 22→15   | 20→13  | 18→12   | 17→11   | 16→10   | 15→9    |
| 需要圈内累计（秒）            | 3       | 3.5    | 4       | 4.5     | 5       | 6       |

- 适应期 1.5 秒：鱼在中心不动，最后 0.5 秒加速到巡游；期间累计冻结（不加不减），时限从适应期后开始算。
- 时限：适应期后统一 15 秒。圈内每 tick +1、圈外 −2（2026-09-28 确认）：净速率 3p−2（p 为在圈比例），0★ 需 p≥73%，5★ 需 p≥80%。
- 鱼圈按累计进度收缩（越接近上鱼越小），掉进度会变回大；同时 ±2 呼吸。
- 冲刺前 0.4 秒涟漪预警，冲刺 0.6 秒、1.8 倍速并转向，冲刺后至少 2 秒冷却。
- 游走：32 个固定方向 + 定点整数运算（不用 `Math.sin/cos`，保证跨浏览器回放一致）；碰到水域边缘反弹，鱼圈始终完整在水面。
- 完美提竿：累计起始 +15%。精准抛投（55–80%）：鱼圈最小半径 +1。判定圈比绘制圈大 1 个单位；竿尖点指数平滑（α≈0.3）。

平衡验证（`tests/simulation/fight-balance.test.ts`，每档 40 条鱼）：模拟玩家看到的是 `延迟` 之前的鱼，并按最近运动外推（平滑追踪），加手抖。

| 模拟玩家          | 0★   | 3★   | 5★   | 实测（100 条）                    |
| ----------------- | ---- | ---- | ---- | --------------------------------- |
| 新手 0.4 秒 / ±3  | ≥80% | —    | ≤10% | 100 / 100 / 100 / 95 / 2 / 0      |
| 熟练 0.25 秒 / ±2 | ≥95% | ≥60% | ≤50% | 100 / 100 / 100 / 100 / 100 / 32  |
| 老练 0.15 秒 / ±1 | ≥95% | ≥90% | ≥80% | 100 / 100 / 100 / 100 / 100 / 100 |

同一玩家星级越高钓获率不升。模拟只校准相对难度；真实手感（倾斜角、平滑）另在实机调（020）。

## 失败与兜底

- 体感模式在准备抛竿时锁定到这一竿（run 记录 `mode: 'motion'`），中途不切到按钮版张力遛鱼：两种遛鱼模型不同。
- 遛鱼中传感器读数中断：暂停这一竿并提示；**手指拖动竿尖点**作为同一模型的兜底输入，不会卡死。
- 等待与咬钩阶段**点一下水面**等同上扬提竿；没有倾斜读数时甩竿朝正前方（方向 0）。
- 暂停中的一竿忽略全部手势，提示"点「继续钓鱼」"；零点只在新一竿开始、进入遛鱼时重设，城市时钟刷新不影响瞄准。
- 刷新后传感器需再次点击授权：进行中的体感一竿会重新显示开启卡片；拒绝或不支持时设置里写明原因（可重试授权）。
- 叠层是覆盖画布水域的正方形平面，百分比坐标与 Core 的 0–100 判定一致。
- 拒绝权限、非 HTTPS、无陀螺仪：体感开关不可用，自动使用冻结的按钮版本。
- 失败垃圾：0–2★ 在"脱钩"（提竿超时或遛鱼超时）时按现有概率掉落；惊鱼不直接失败。

## Core 模型

- 新的纯函数模块 `minigames/angling-motion.ts`，与按钮版 `angling.ts` 并存；按 run 的 `mode` 分派。
- 输入命令：`FISH_CAST { power }`（已有）、新增 `FISH_STRIKE`（Core 用当前 tick 与咬口 tick 判断窗口）、`FISH_MOTION_CONTROL { x, y, ticks }`（复用，遛鱼时为竿尖点）。
- 鱼的位置、鱼圈半径、假咬口时刻都是 `(seed, 星级, phaseTick)` 的纯函数，不入档；存档只保存累计值、阶段与 tick，可续玩与回放。需要升级 saveVersion。
- View 只上报角速度峰值换算的力度、上扬时刻和平滑后的竿尖坐标，不决定成败。

## 验收

- 单元测试：各星级鱼路径与半径可复现；圈内累计/衰减；惊鱼规则；提竿窗口边界；时间分块等价；存档续玩。
- E2E（WebKit/Chromium 注入 `devicemotion`/`deviceorientation`）：一竿完整流程、假咬口惊鱼、遛鱼中断后手指兜底、按钮版不受影响。
- 实机：iOS Safari 与 Android Chrome 各一台，确认阈值、手感与疲劳度；数值按实机调整。
