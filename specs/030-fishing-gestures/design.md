# 030 设计：体感钓鱼（手机即鱼竿）

按钮版本**冻结**：保持现有流程（准备 → 按住蓄力 → 绿区提竿 → 张力遛鱼），不做改动。本设计只针对开启体感后的流程。

## 市面对照（2026-09 检索）

| 已有做法                       | 例子                                                                                         | 与本设计的关系                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 挥动设备抛竿，速度决定距离     | Fishing Master（手机）、Reel It In（手机原型）、Wii Fishing Resort、Switch Legendary Fishing | 抛竿沿用这一成熟手感，不是差异点                         |
| 旋转手柄收线 / 跟随拉力转竿    | Legendary Fishing、Wii Fishing Resort                                                        | 不采用：手机上旋转收线易疲劳、易误触                     |
| 倾斜手机操控鱼钩               | Ridiculous Fishing                                                                           | 相近的倾斜操控，但用于躲鱼/收集                          |
| 把控制条压在游动的鱼上累计进度 | Stardew Valley（一维、按键）                                                                 | 遛鱼的核心循环同源，本设计改为**二维 + 体感 + 收缩鱼圈** |
| 倾斜操控下沉的鱼钩抓鱼/躲鱼    | Ninja Fishing、Ridiculous Fishing（手游）                                                    | 倾斜操控相近；遛鱼以点击或无对抗为主                     |
| 挥动手机抛竿、接鱼             | Fishy Business（手游）                                                                       | 抛竿手感相近                                             |

差异点（检索范围内的手游未见同类遛鱼）：**倾斜竿尖在二维水面追一个游动、呼吸收缩的鱼圈**，加上"假咬口 → 真咬口'！'→ 反射上扬"的判断。单项有先例，组合少见。

## 默认模式（2026-09-28 确认）

- 支持体感的手机**默认使用体感版本**（替换现有文档中"体感默认关闭"）。
- 首次进入钓点显示一张卡片"开启体感钓鱼（倾斜瞄准、甩动抛竿）"，点一下即请求权限（iOS 必须由点击触发）；旁边提供"改用按钮"。
- 无需权限的浏览器（多数 Android）收到首个有效读数即启用，不弹卡片。
- 拒绝权限、非 HTTPS、无陀螺仪：自动使用冻结的按钮版本。
- "钓具 → 设置"可随时切换，选择按设备记住（View 本地偏好，不入存档）。

## 握姿与校准

- 竖握手机，屏幕朝向自己，**手机顶端就是竿尖**。单手即可，手腕动作足够，不需要大幅挥臂。
- 每次进入瞄准时自动把当前握姿记为零点，不需要手动校准；任何坐姿、躺姿都可玩。
- 所有动作按**角速度**（陀螺仪 `rotationRate`）判定，不依赖重力方向，Android/iOS 一致。

## 一竿的流程

| 阶段   | 玩家动作                                                              | 反馈                                                     | 判定（Core）                                                                            |
| ------ | --------------------------------------------------------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| 1 瞄准 | 左右倾斜（roll）移动水面准星                                          | 准星与抛物线预览                                         | 方向 −45°～45°，甩竿开始时锁定                                                          |
| 2 甩竿 | 竿尖**先向后上扬**，0.7 秒内**快速向前下压**                          | 后扬到位轻震一下；出竿"嗖"声与划线                       | View 报峰值角速度 → 力度 0–100；55–80% 为精准抛投。此刻才扣体力和鱼饵                   |
| 3 等待 | 拿稳即可                                                              | 浮漂漂动；**假咬口**：轻点头 + 轻震                      | 假咬口次数由种子和星级决定                                                              |
| 4 咬钩 | 看到 **"！"** + 强震，**快速上扬**（竿尖向上的角速度超过阈值）        | 反应越快判定越好：完美 / 成功                            | 窗口按星级；假咬口时上扬 = 惊鱼：真咬口推迟、窗口变短一档；超时脱钩                     |
| 5 遛鱼 | 倾斜手机移动**竿尖点**（roll → 左右，pitch → 前后），追住**金边鱼圈** | 点在圈内：圈变绿、竿身弯、持续轻震；圈外：变红、断续提示 | 圈内累计 +1/tick，圈外按比例衰减；鱼圈跟随鱼游动并呼吸收缩；鱼冲刺前 0.4 秒出现涟漪预警 |
| 6 出水 | 进度满时鱼跃出水面                                                    | 结果卡、鱼的大小                                         | 与现有结算一致；遛鱼超时 = 脱钩                                                         |

## 难度规格（初版，按星级；实现时写入 `content/fishing/spec.ts`，数值可再调）

| 星级                              | 0     | 1     | 2     | 3     | 4    | 5    |
| --------------------------------- | ----- | ----- | ----- | ----- | ---- | ---- |
| 提竿窗口（秒）                    | 0.9   | 0.8   | 0.7   | 0.6   | 0.52 | 0.45 |
| 假咬口次数                        | 0–1   | 1     | 1–2   | 2     | 2–3  | 3    |
| 鱼速（水面单位/秒，水面 100×100） | 12    | 16    | 20    | 26    | 32   | 40   |
| 转向间隔（秒）                    | 2.0   | 1.6   | 1.3   | 1.0   | 0.8  | 0.6  |
| 每次转向冲刺概率                  | 0     | 5%    | 10%   | 15%   | 20%  | 25%  |
| 鱼圈半径 起始 → 最小              | 22→14 | 20→12 | 18→11 | 16→10 | 15→9 | 14→8 |
| 需要圈内累计（秒）                | 3     | 4     | 5     | 6     | 7    | 8    |
| 遛鱼时限（秒）                    | 20    | 22    | 24    | 26    | 28   | 30   |

- 圈外衰减：每 tick 扣 0.5 tick 的累计（先行值）。
- 完美提竿：遛鱼起始累计 +15% 或鱼圈起始半径 +2（二选一，试玩后定）。
- 精准抛投（55–80%）：鱼圈最小半径 +1，沿用现有"精准抛投给予容错"的规则。
- 判定圈比绘制圈大 1 个单位，吸收倾斜噪声；竿尖点做指数平滑（α≈0.3）。

## 失败与兜底

- 体感模式在准备抛竿时锁定到这一竿（run 记录 `mode: 'motion'`），中途不切到按钮版张力遛鱼：两种遛鱼模型不同。
- 遛鱼中传感器读数中断：暂停这一竿并提示；**手指拖动竿尖点**作为同一模型的兜底输入，不会卡死。
- 等待与咬钩阶段**点一下水面**等同上扬提竿；没有倾斜读数时甩竿朝正前方（方向 0）。
- 暂停中的一竿忽略全部手势，提示"点「继续钓鱼」"；零点只在新一竿开始、进入遛鱼时重设，城市时钟刷新不影响瞄准。
- 刷新后传感器需再次点击授权：进行中的体感一竿会重新显示开启卡片；拒绝或不支持时设置里写明原因（可重试授权）。
- 叠层是覆盖画布水域的正方形平面，百分比坐标与 Core 的 0–100 判定一致。
- 拒绝权限、非 HTTPS、无陀螺仪：体感开关不可用，自动使用冻结的按钮版本。
- 失败垃圾：0–2★ 在"脱钩"（提竿超时或遛鱼超时）时按现有概率掉落；惊鱼不直接失败。

## Core 模型

- 新的纯函数模块 `minigames/angling-motion.ts`，与按钮版 `angling.ts` 并存；按 run 的 `mode` 分派。
- 输入命令：`FISH_CAST { power }`（已有）、新增 `FISH_STRIKE`（Core 用当前 tick 与咬口 tick 判断窗口）、`FISH_MOTION_CONTROL { x, y, ticks }`（复用，遛鱼时为竿尖点）。
- 鱼的位置、鱼圈半径、假咬口时刻都是 `(seed, 星级, phaseTick)` 的纯函数，不入档；存档只保存累计值、阶段与 tick，可续玩与回放。需要升级 saveVersion。
- View 只上报角速度峰值换算的力度、上扬时刻和平滑后的竿尖坐标，不决定成败。

## 验收

- 单元测试：各星级鱼路径与半径可复现；圈内累计/衰减；惊鱼规则；提竿窗口边界；时间分块等价；存档续玩。
- E2E（WebKit/Chromium 注入 `devicemotion`/`deviceorientation`）：一竿完整流程、假咬口惊鱼、遛鱼中断后手指兜底、按钮版不受影响。
- 实机：iOS Safari 与 Android Chrome 各一台，确认阈值、手感与疲劳度；数值按实机调整。
