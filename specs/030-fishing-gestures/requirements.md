# 030 体感钓鱼重设计：甩竿、"！"提竿、竿尖追鱼圈

- 状态：验证中（批次 2 实现；自动化通过，待实机调手感，见 020）
- 范围（2026-09-28 更新）：**只重做体感版本**；无体感的按钮版本冻结，保持现有流程与张力遛鱼。完整设计见 [design.md](design.md)。支持体感的手机**默认使用体感**。
- 来源：用户 2026-09-28 在 HTTPS 测试版试玩后的反馈："要点的按钮太多了""按钮含义混乱""整体顺序再整理"

## 问题

当前一竿要依次操作：点池塘 → 进入钓点 → 调方向与近远滑杆 → 点"准备抛竿"（此时扣资源）→ 同一按钮按住蓄力 → 点击提竿 → 按住/松开控制张力。按钮多、同一按钮含义不断变化，近远滑杆不影响鱼池。

## 目标流程

1. 到岸后点池塘**直接进入河畔**（去掉单独的"进入钓点"）。
2. **瞄准**：倾斜手机或拖动准星选择方向；去掉近远滑杆，距离由甩竿速度决定。
3. **甩竿**：手机快速上扬后下压（模拟甩竿），挥动的峰值角速度决定力度/距离；甩出时才扣体力与鱼饵。
4. **等待**：浮漂等待。
5. **咬钩**：出现 **"！"** 并伴随可选震动；在限定时间内**快速上扬**提竿，超时脱钩。
6. **遛鱼（无拉线）**：提竿后稍后出现跟随鱼移动的**金边鱼圈**；鱼自由游动，星级越高游动频率越高，鱼圈周期性收缩扩张、以收缩为主。玩家倾斜手机移动一个**点**（竿尖），点在圈内时鱼圈由红变绿，**圈内累计时间**达到要求即钓到；离圈时累计缓慢衰减（数值待定）。复用现有二维点/圈判定（`FISH_MOTION_CONTROL`），圆圈改为随鱼移动、半径按节奏变化、计数由"连续"改为"累计"。
7. **结算**：结果卡，鱼篓出售/赠送不变。

## 移除（仅体感版本）

- 张力控制：按住收线/松开放线、张力条、张力极端断线，以及按钮的"收线"含义。
- 失败原因从"断线"改为"提竿超时"与"遛鱼时间耗尽"；0–2★ 失败垃圾规则与概率不变，改挂在新的失败原因上。

## 约束

- 无体感、拒绝权限或非 HTTPS 时使用冻结的按钮版本；体感遛鱼中读数中断时，手指拖动竿尖点兜底。
- View 只上报动作峰值速度与时刻、圆圈位置等输入；力度、提竿成功、鱼的游动与圈内累计由 Core 纯函数用整数 tick 与种子决定，可存档续玩与回放。
- 资源只扣一次；取消/失败不退款；结算触摸不能穿透开启下一竿（沿用现有要求）。
- 鱼种、水域、鱼饵、星级、图鉴与经济数值不在本需求内改变，除非另行确认。

- 倾斜读数平滑方式与判定容差（判定圈略大于绘制圈）。
