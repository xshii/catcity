# 000 代码瘦身与规格集中

- 状态：进行中
- 来源：用户 2026-09-28，接手 Codex 代码后的检视（Core / Application / View / Harness+Tests 四路）

## 目标

1. 删除死代码与冗余，合并重复逻辑，玩法行为不变。
2. 消除魔鬼数字与魔鬼字符串；钓鱼小游戏的全部数值规格集中在一个文件。
3. 目录按五类归位：体感独立、美工（绘图与调色板）独立、仅测试使用的实现移到 `tests/helpers/`。
4. 删除存档中可推导或从未使用的字段（saveVersion 升级，旧档按现有契约显式拒绝）。
5. 测试瘦身与提速，不降低覆盖的行为。

## 验收标准

- 玩法规则、数值与现有文档一致；除修正与规则矛盾的线索文案外，玩家可见行为不变。
- 钓鱼数值（体力、鱼篓、绿区、咬钩期限、奖励、遭遇阈值、补给/垃圾概率）只在 `src/content/fishing-spec.ts` 定义，Core、小游戏与 View 均从此读取。
- `CommandError` 只接受类型化错误码；View 的错误提示表按错误码类型检查。
- 生产命令 schema 不含调试命令。
- saveVersion 11 精确往返；v10 及更早存档被拒绝并保留原数据直到显式重置。
- `npm run check` 与 `npm run harness` 通过，截图人工检查。

## 不做

- 不改变玩法数值、不新增功能。
- View 通信方式（DOM 事件总线）与 `fishing/panel.ts` 拆分另立 spec。
