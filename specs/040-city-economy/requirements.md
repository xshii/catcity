## 规则（数值在 `src/content/city.ts`）

| 项目     | 规则                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 猫咖收入 | 每位客人每完整营业 60 游戏分钟 2 金币；每家沿用自己的建造时刻计时，搬移不重置 |
| 客人     | 有住所的猫，住所（公寓）到猫咖的格距 ≤ 3；看的是住所，不是猫此刻站的位置      |
| 归属     | 每只猫只算一家的客人：离住所最近的一家；同距离时算建筑 ID 较早的一家          |
| 上限     | 每家最多 5 位客人；超出的猫不改去别家，这一家只按 5 位结算                    |
| 无客人   | 没有客人的猫咖没有收入，也不产生 `IncomeGenerated` 事件                       |
| 猫咖价格 | 第 n 家 `300 × 1.5^(n−1)`：300、450、675、1010、1520、2280…                   |
| 公寓价格 | 第 n 座 `250 × 1.4^(n−1)`：250、350、490、685、960、1345、1880、2635…         |
| 土地价格 | `50 + 25 × d`                                                                 |
| 搬移     | 免费                                                                          |

- **格距**：沿行列的步数 `|Δx| + |Δy|`（`gridDistance`）。
- **n**：世界里同类建筑的现有数量 + 1，由 `world.buildings` 推导，不入档。当前没有建筑拆除，所以价格只升不降。
- **取整**：取最接近的 5 的倍数；恰好在两个倍数正中间时向下（`300 × 1.5^3 = 1012.5 → 1010`，与 037 表中的数列一致）。用 BigInt 做精确整数运算（`buildingPrice`），不经过浮点。
- **d**：地块到起始城区矩形（`CITY_START.starterDistrict`，`x,y ∈ 3..6`）的格距减 1，最小为 0。到矩形的格距 = 横向超出的格数 + 纵向超出的格数。与城区共边的地块 d = 0（50 金币）；只与城区对角相接的地块 d = 1（75 金币）；10×10 地图上最远的角 d = 5（175 金币）。
- 客人按"有住所的猫"计算，不区分伙伴猫与将来的居民猫（NPC）；本片不为 NPC 建任何东西。
- 拒绝的命令（金币不足等）不改变世界、不扣费；价格按下命令时的数量计算。

## 新手指引

顺序改为 **安家 → 入住 → 在家附近开猫咖 → 第一笔收入 → 共同回忆**，仍是三个步骤标记（猫咪入住、猫咖收入、共同回忆），阶段由世界状态推导（`guideProgress`）：

| 阶段     | 条件                        | 提示                                                   | 按钮指向                  |
| -------- | --------------------------- | ------------------------------------------------------ | ------------------------- |
| home     | 没有任何猫有住所            | 建一座猫公寓；已有公寓则"点猫公寓，让 Mochi 入住"      | 推荐空地，或已有的公寓    |
| cafe     | 没有一家猫咖有客人          | 在公寓 3 格内建猫咖；已有猫咖则"把猫咖搬到公寓 3 格内" | 住所 3 格内的空地，或猫咖 |
| earn     | 有客人的猫咖营业未满 1 小时 | 等营业满 1 小时，可调快速度                            | 顶部速度键                |
| remember | Mochi 还没有共同钓鱼记忆    | 点池塘一起钓鱼                                         | 池塘                      |
| grow     | 以上都完成                  | 自由建设                                               | 聊共同回忆                |

推荐空地必须是已拥有、无路面、无猫无建筑、紧挨道路的草地（原来的推荐不检查是否挨着道路）。

## 经济目标与测得的数值

`tests/simulation/economy.test.ts`，种子 42，16 只猫、8 座公寓、4 家猫咖：

| 目标                                 | 断言          | 测得    | 结果       |
| ------------------------------------ | ------------- | ------- | ---------- |
| 猫咖位置合适时每游戏小时总收入       | = 32          | 32      | 通过       |
| 猫咖挤在一起时的总收入               | 0 < 收入 < 32 | 小于 32 | 通过       |
| 建成这座城市所需金币（含土地与道路） | 11,000–12,000 | 11,310  | 通过       |
| 4× 挂机 1 现实小时 ≤ 1.5 × 钓鱼收入  | ≤ 2,250       | 7,680   | **未通过** |

建设总价的构成：猫咖 300 + 450 + 675 + 1010 = 2,435；公寓 250 + 350 + 490 + 685 + 960 + 1345 + 1880 + 2635 = 8,595；土地 5 格 × 50 = 250；土路 1 格 30。起始城区里挨着道路的空地只有 8 块，12 座建筑还需要 4 块地，其中 2 块要先买一格地铺路才能接上路网。

这个总价低于 037 估算的"3.5 万–4.5 万"：那个估算按 24 只猫（含尚不存在的居民猫）、12 座公寓、5 家猫咖计算。本片不为追上旧估算而改价格，只记录测得的数值。

在 12 块可用地上放 4 家猫咖共有 495 种放法，只有 9 种能让 16 只猫都成为客人，所以"放得好"确实需要规划。

## 未通过的目标与建议

每位客人每游戏小时 2 金币时，住满的城市每游戏小时 32 金币。4× 速度下 1 现实小时 = 240 游戏小时，挂机收入 7,680，是上限 2,250（1.5 × 25 × 60）的 3.4 倍。1× 下是 1,920，低于上限：这条目标只在 1× 成立。"每游戏小时总收入 32"与"4× 挂机不超过 2,250"两个目标不能同时满足，要满足后者，全城每游戏小时不能超过 9 金币。

断言按需求原样保留、目前失败，没有为了通过而改动。建议（任选其一，需用户决定）：

| 方案 | 改动                                                 | 全城每游戏小时 | 4× 挂机 1 小时 | 代价                                                   |
| ---- | ---------------------------------------------------- | -------------- | -------------- | ------------------------------------------------------ |
| A    | 结算周期 60 → 240 游戏分钟，每位客人仍是 2 金币      | 8              | 1,920          | "每游戏小时 32"的目标改为 8；第一笔收入 4× 下等 1 分钟 |
| B    | 目标改为按 1× 衡量，数值不动                         | 32             | 7,680          | 4× 下挂机是钓鱼的 5 倍，猫咖取代钓鱼                   |
| C    | 猫咖收入不随时钟速度加快（改时钟适配层，不只是数值） | 32             | 1,920          | 超出本片范围                                           |

建议 A：只改 `BUILDINGS.CAT_CAFE.intervalMinutes` 一个数，改后只挂机 4× 建成城市约 8.9 小时、边钓鱼边经营约 3.8 小时（与现在 1× 的数字相同），钓鱼仍是前期主要来源。

## 已知限制

- 指引的"已有收入"是推导值：有客人的猫咖营业满 1 小时即算完成。若猫咖先空开了 1 小时、之后才有猫入住，这一步会在入住时立刻显示完成，而第一笔收入要等到下一个整点。
- 一家猫咖被分到超过 5 只猫时，多出的猫不算任何一家的客人；要靠再建一家更近的猫咖分流。
- 第 39 家猫咖起价格超过金币上限（10 亿），实际买不起；建筑数量上限仍是 100。
