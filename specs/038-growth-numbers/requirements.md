# 038 成长数值

- 状态：验证中（代码与测试完成，节奏模拟全部在目标区间内；等待完整 Gate / Harness）
- 来源：2026-09-29 用户："请你仔细设计一下这个数值系统不要太快速到顶"。设计见 037 猫咪生活的数值设计（`specs/037-cat-life/numbers.md`）；本片实现其中第 4、5、6 节，并删除饥饿（037 需求第 11 节）。
- 相关：[032 心情](../032-mood/requirements.md)、[036 关系等级](../036-bond-levels/requirements.md)

## 现状

钓技每级固定 40 经验，约 25 条鱼满级。关系每游戏小时最多 +1，时钟调到 4× 时约 15 分钟到"家人"。成长由游戏时钟限速，而时钟可以加速；曲线是线性的。`needs.hunger` 只有送鱼会减，没有任何效果。

## 规则（数值在 `content/fishing/spec.ts`、`content/care.ts`、`content/mood.ts`）

### 钓技

- 升到第 n 级累计需要 `30 × (n − 1) × n × (n + 1) / 3` 经验（`skillXp`）：60、240、600、1200、2100、3360、5040、7200、9900；最高仍是 10 级。
- 钓到鱼的经验仍是 `10 + 5 × 星级`；开心的一竿（开竿时记下的 `happy`）×1.5，向下取整。
- 月光湖的钓技要求从 4 改为 5；其余水域不变。每级效果不变（绿区宽 +2）。

### 关系点数

`playerBond` 是点数，不再有每游戏小时一次的上限。

| 来源                  | 点数        | 限制                |
| --------------------- | ----------- | ------------------- |
| 一起钓到鱼            | +2          | 无                  |
| 送喜欢的鱼 / 其他鱼   | +3 / +1     | 消耗一条鱼          |
| 聊天                  | +1          | 每只猫每游戏日 1 次 |
| 猫在那一刻开心（≥80） | 以上各项 +1 | —                   |

- 等级门槛（`BOND_LEVELS`）：初识 0、熟悉 25、信任 150、亲密 500、家人 1500。每级心情平静点 +3 不变。
- "那一刻"的心情取这件事自己加心情之前的值：心情 79 时钓到鱼，心情到 82，关系只 +2。
- 游戏日是 1440 游戏分钟，按 `world.minute` 整除（`gameDay`）；新游戏从第 0 日 7:00 开始。
- 聊天的心情 +2 与关系分开：每只猫每游戏小时最多一次，和今天一样；钓到鱼或送鱼不再占用它。
- 补给、垃圾、鱼跑了、主动收竿不增长；关系从不下降。

### 心情

- 整点回归：心情高于 80 时每小时 4，否则每小时 2；都不越过平静点。
- 心情 ≥80 时，所有加心情的来源减半（向下取整，至少 1）：钓到鱼、送鱼、聊天、住在家旁。减心情不变。
- 钓到鱼的心情从 +3 改为 +5（鱼跑了仍是 −3）。

### 删除饥饿

- 删除 `needs.hunger`：存档、新猫初始值、送鱼的处理。`needs` 只剩体力。界面原本没有显示饥饿。

## 节奏模拟（`tests/simulation/pacing.test.ts`）

模拟玩家带着 Mochi 只钓鱼，从新游戏到钓技满级且关系到"家人"，每一步都是 Core 命令。手感沿用钓鱼平衡模拟的新手与熟练两档（`tests/helpers/motion-player.ts`）。模拟的假设：每游戏小时抛一竿（河畔 1× 时钟下约每分钟一条鱼）；始终去最新开放的水域，熟练玩家钓 Mochi 能钓的最好的鱼（鲶鱼、海鲷、锦鲤），新手钓不超过 2★ 的鱼（鲈鱼、鲭鱼）。

| 断言                       | 目标区间 | 新手 | 熟练 | 结果 |
| -------------------------- | -------- | ---- | ---- | ---- |
| 到芦苇河湾的鱼数           | 4–8      | 5    | 5    | 通过 |
| 到月光湖的鱼数             | 45–70    | 54   | 45   | 通过 |
| 钓技满级的鱼数             | 280–450  | 432  | 294  | 通过 |
| 关系到"信任"的鱼数         | 50–90    | 66   | 66   | 通过 |
| 关系到"家人"的鱼数         | 500–800  | 650  | 644  | 通过 |
| 熟练玩家只钓鱼时的开心占比 | 30–50%   | 31%  | 33%  | 通过 |

撸猫、金币与建设的各行不在本片。熟练玩家到月光湖的 45 条正好在区间下沿，新手满级的 432 条接近上沿，余量很小。

## 数值调整记录（2026-09-29 用户确认）

第一版按设计原值实现（曲线系数 25、钓到鱼心情 +3），节奏模拟有两项落在区间外：熟练玩家 42 条鱼到月光湖（设计按每条 20 经验估算，熟练玩家钓 3★ 鱼每条 25）；只钓鱼时 750 竿没有一竿开心（心情 79 钓到鱼到 82，整点回归 4 回到 78，开竿时永远在 77–79）。两项互相牵连：开心占比上去后经验 ×1.5 会让所有鱼数再少约 14%。用户决定：曲线系数改为 30，钓到鱼心情改为 +5，目标区间全部不变。

## 开心占比依赖抛竿节奏

开心占比的目标（30–50%）只在**每游戏小时一竿**的节奏下成立。心情的回归走游戏时钟，加心情走操作次数，所以抛得越快占比越高。以后重新调数值时要同时说明节奏。

| 每竿游戏分钟 | 原数值（+3、系数 25）熟练 | 现数值（+5、系数 30）新手 / 熟练 |
| ------------ | ------------------------- | -------------------------------- |
| 60           | 0%                        | 31% / 33%                        |
| 45           | 25%                       | 62% / 66%                        |
| 30           | 49%                       | 95% / 99%                        |
| 20           | 82%                       | 99% / 99%                        |

已知限制：现数值下，每竿不超过 30 游戏分钟的玩家几乎每一竿都开心，经验 ×1.5 对他们接近常态，与设计"不可能做到 100% 开心"不符；此时熟练玩家 37 条鱼到月光湖、230 条满级，低于区间。每竿的实际用时要靠实机试玩确认；若明显短于一游戏小时，需要再调（例如让高位回归与减半更强，或让经验加成按一竿的用时而不是次数计）。

## 不做

- 撸猫、绝育、生育、居民猫、金币与建筑价格。
- 旧档迁移；关系下降、离线结算。
- 每只猫各自的钓技。
