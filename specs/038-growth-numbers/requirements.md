# 038 成长数值

- 状态：验证中（代码与测试完成，节奏模拟全部在目标区间内；等待完整 Gate / Harness）
- 来源：2026-09-29 用户："请你仔细设计一下这个数值系统不要太快速到顶"。设计见 037 猫咪生活的数值设计（`specs/037-cat-life/numbers.md`）；本片实现其中第 4、5、6 节，并删除饥饿（037 需求第 11 节）。
- 相关：[032 心情](../032-mood/requirements.md)、[036 关系等级](../036-bond-levels/requirements.md)

## 现状

钓技每级固定 40 经验，约 25 条鱼满级。关系每游戏小时最多 +1，时钟调到 4× 时约 15 分钟到"家人"。成长由游戏时钟限速，而时钟可以加速；曲线是线性的。`needs.hunger` 只有送鱼会减，没有任何效果。

## 规则（数值在 `content/fishing/spec.ts`、`content/care.ts`、`content/mood.ts`）

### 钓技

- 升到第 n 级累计需要 `27 × (n − 1) × n × (n + 1) / 3` 经验（`skillXp`）：54、216、540、1080、1890、3024、4536、6480、8910；最高仍是 10 级。
- 钓到鱼的经验仍是 `10 + 5 × 星级`；开心的一竿（开竿时记下的 `happy`）×1.5，向下取整。
- 月光湖的钓技要求从 4 改为 5；其余水域不变。每级效果不变（绿区宽 +2）。

### 关系点数

`playerBond` 是点数，不再有每游戏小时一次的上限。

| 来源                | 点数        | 限制                  |
| ------------------- | ----------- | --------------------- |
| 一起钓到鱼          | +2          | 无                    |
| 送喜欢的鱼 / 其他鱼 | +3 / +1     | 每只猫每游戏日前 3 条 |
| 聊天                | +1          | 每只猫每游戏日 1 次   |
| 猫开心（≥80）       | 以上各项 +1 | —                     |

- 等级门槛（`BOND_LEVELS`）：初识 0、熟悉 25、信任 150、亲密 500、家人 1500。每级心情平静点 +3 不变。
- 开心的判定：钓到鱼看这一竿开竿时记下的 `happy`，与经验 ×1.5 是同一个；送鱼和聊天看那一刻的心情，取这件事自己加心情之前的值（心情 79 时送喜欢的鱼，心情到 87，关系只 +3）。
- 礼物每只猫每游戏日只有前 3 条算数（`BOND.giftsPerDay`）；之后的礼物照样收下、消耗这条鱼、记为最近的礼物，但不加关系也不加心情，提示里温和地说明。否则用免费面包在池塘钓 Mochi 喜欢的鱼、每条都送，每条鱼最多 7 点关系、每一竿都开心，约 215 条鱼就到"家人"。
- 游戏日是 1440 游戏分钟，按 `world.minute` 整除（`gameDay`）；新游戏从第 0 日 7:00 开始。
- 聊天的心情 +2 与关系分开：每只猫每游戏小时最多一次，和今天一样；钓到鱼或送鱼不再占用它。
- 补给、垃圾、鱼跑了、主动收竿不增长；关系从不下降。

### 心情

- 整点回归：开心的猫（≥80，与减半同一条线）每小时 4，否则每小时 2；都不越过平静点。开心的猫最低落到 77，也就是 79 的猫落到的地方：回归速度在 80 处突变，不设这个下限的话 80 的猫会落到 76，比 79 的猫更低（`moodAfterDrift`）。
- 心情 ≥80 时，加心情的来源减半（向下取整，至少 1）：送鱼 +8 → +4、+3 → +1，聊天 +2 → +1；住在家旁的 +1 减半后仍是 +1。减心情不变。
- 钓到鱼的心情 +3，但最多到 79（`MOOD.happy − 1`）；已经开心（≥80）的猫钓到鱼心情不变，既不加也不减（`core/mood.ts` 的 `liftCalmMood`）。送鱼、聊天、住在家旁和之后的撸猫可以越过开心线。鱼跑了每次仍是 −3。对玩家的一句话：**钓到鱼能让猫心情变好，但要让它真正开心，得摸摸它或送它喜欢的鱼。**

### 删除饥饿

- 删除 `needs.hunger`：存档、新猫初始值、送鱼的处理。`needs` 只剩体力。界面原本没有显示饥饿。

## 节奏模拟（`tests/simulation/pacing.test.ts`）

模拟玩家带着 Mochi 只钓鱼，从新游戏到钓技满级且关系到"家人"，每一步都是 Core 命令。手感沿用钓鱼平衡模拟的新手与熟练两档（`tests/helpers/motion-player.ts`）。模拟的假设：固定节奏抛竿，每竿 20、30、45、60 游戏分钟各跑一遍；始终去最新开放的水域，熟练玩家钓 Mochi 能钓的最好的鱼（鲶鱼、海鲷、锦鲤），新手钓不超过 2★ 的鱼（鲈鱼、鲭鱼）。"一直开心"的玩家每竿之前心情都是 100（代替不停撸猫的玩家，模拟直接设定心情），是成长最快的上限。

模拟的开销（2026-09-30）：每一档玩家、每个节奏完整玩一遍，四个节奏都保留，全部断言读同一次结果。远程 CI 上每条用例曾超过 5 秒；原因是遛鱼每个 tick 都从头重走鱼的路径（`fishPath`），占一次模拟的约六成。现在 `minigames/angling-motion.ts` 记住当前这一竿的路径（只由种子和鱼种决定，答案不变），等待咬钩的 tick 成批提交；带覆盖率时每条用例从约 1000 毫秒降到约 155 毫秒，没有提高超时、没有改断言，每一步仍是 Core 命令。

模拟里世界的每次改变都是 Core 的 reducer 执行的命令；命令经 Core 的命令 schema 校验，只有每一竿第一条之后的竿尖 tick 输入不再逐条校验（只有坐标和 tick 数不同，全部校验会让一次模拟慢三倍）。命令直接作用在同一份状态上，整个世界在模拟结束时校验一次。"一直开心"的心情是模拟直接写进状态的，没有命令能做到。

## 数值调整记录

1. 第一版按设计原值（曲线系数 25、钓到鱼每次 +3）：熟练玩家 42 条鱼到月光湖；每游戏小时一竿时没有一竿开心（目标 30–50%）。
2. 2026-09-29 系数 30、钓到鱼每次 +5：每游戏小时一竿时开心 31% / 33%，但每竿 45 游戏分钟 66%，30 与 20 分钟 99%。原因：加心情按次数、减心情按游戏时间，抛得快就一直开心，经验 ×1.5 成为常态。
3. 2026-09-30 试过按游戏时间给心情：每小时一次 +3 或更细的回归刻度时，心情贴着 80 摆动，开竿那一刻在线上还是线下取决于抛竿与整点的相位，占比在 0% 与 65% 之间跳；每 15 个游戏小时一次 +34 时占比稳定在 33–37%，但一条鱼给出全部心情、其余不给。
4. 2026-09-30 用户决定现在的规则：钓到鱼的心情到 79 为止，开心只能靠撸猫或送鱼。开心不再与抛竿节奏有关。
5. 曲线系数 27：只钓鱼没有经验加成，系数 26 时熟练玩家 44–45 条到月光湖（低于 45），系数 28 时新手 464 条满级（高于 450）；只有 27 同时满足。

## 已知限制

- **余量很小。** 熟练玩家到月光湖 46 条（下沿 45），新手满级 448 条（上沿 450）。两条约束方向相反：新手满级 ÷ 熟练到月光湖 ≈ 9.7，区间允许的上限是 10。要留出余量，需要放宽其中一个区间，或改变两档玩家的经验差距（取决于模拟里两档玩家钓哪些鱼）。
- 一直开心的玩家：月光湖 32–38 条、满级 206–299 条，低于常规区间的下沿（45、280）；熟练玩家的 32 与 206 离下限 30 与 190 不远。关系 50 / 500 条正好在区间下沿。
- 撸猫还没有做：在它上线之前，让猫开心的手段只有送鱼（喜欢的鱼 +8）、聊天（每小时 +2）和住在家旁（每小时 +1）。037 里"钓鱼间隙撸猫 70–85% 开心"的目标留给撸猫那一片验证。
- 鱼跑了每次 −3 仍按次数计。
- 聊天和礼物的每日次数在游戏日的分界清零：午夜前后相隔一分钟的两次都算数；新游戏从 7:00 开始，第 0 日只有 17 小时。保持现状。
- 80 处的减半是突变的：喜欢的鱼在心情 79 时送到 87，在 80 时只到 84。保持现状。
- 送礼的玩家抛得越慢，每条鱼摊到的礼物越多（每竿 60 游戏分钟时 583 条到"家人"，离下限 500 还有余量）。

## 不做

- 撸猫、绝育、生育、居民猫、金币与建筑价格。
- 旧档迁移；关系下降、离线结算。
- 每只猫各自的钓技。

## 验收

- 单测：经验曲线每级边界与封顶、开心经验取整、月光湖门槛；关系每个来源的点数、开心加一的边界（79 / 80）、聊天每日一次与跨日、上限、存档往返与非法 `chatBond`；心情高位回归的边界、每个来源的减半、减心情不变、聊天每小时一次且不受关系影响；被拒绝的命令不改变世界。
