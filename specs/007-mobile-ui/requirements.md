# 007 手机单屏界面与导航

- 状态：验证中
- 来源：原型需求；契约见 [界面与输入](../../docs/ui-layout.md)

## 需求

固定单屏（`100dvh`），主要操作不靠页面滚动；小城与钓点各有四个入口，菜单跟随地点。触摸与键盘可完成完整玩法。390×844、360×640 与桌面布局都在视口内。
