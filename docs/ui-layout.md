# 界面与输入契约

游戏使用固定单屏：场景铺满整个视口，界面浮在场景上（spec 031），手机与桌面结构相同。主要操作不依赖页面或面板纵向滚动；长内容通过分组/分页显示，不能用裁剪隐藏功能。界面配色见下文「视觉基调」；代码绘图服务辨认角色和反馈，不改变世界状态。

## 场景与导航

| 场景 | 导航与主操作                                                          |
| ---- | --------------------------------------------------------------------- |
| 小城 | 指引 / 猫咪 / 出游；地图铺满，点地、建筑、猫或水域后浮出操作卡        |
| 钓点 | 钓具 / 鱼篓 / 图鉴 / 猫咪；水面铺满，鱼竿键、绿区条及结果卡浮在水面上 |

「猫咪」面板两个场景共用，分页「猫咪」（名册、体力、邀请 Pepper）、「说说话」、「共同回忆」；没有常驻侧栏。

名册卡与「说说话」头部显示心情档位（spec 032）：档位只取 Core 的 `moodBand`，界面配表情和文字（😸 开心 / 😺 平静 / 😾 有点闷 / 😿 低落），读屏读 aria-label 的纯文字；开心时多一行"开心：遛鱼圈更大"。心情变化不弹窗：一竿结束或送礼让档位变了，结果卡、钓鱼结果与送礼提示末尾带一句（如"Mochi 心情好起来了（开心）"）。文案集中在 `view/shell/mood.ts` 的 `MOOD_COPY`。

猫咪表情（风格板「猫咪表情」）：地图上的猫、河畔陪伴的猫与名册头像都是圆脸、樱花粉腮红、暖棕描线，表情与耳朵随档位变：开心眯眼笑、耳朵立起；平静圆眼、耳朵立起；有点闷一字眼、耳朵半垂；低落垂眼带泪、耳朵垂下。空闲恢复体力（Core 的 `catIdle` 且体力未满）时蜷成一团打瞌睡，代替原来的 zZ 文字，名册卡另有读屏可读的"在休息"；步行或钓鱼中的猫不蜷起。姿势由纯函数 `view/art/cat-look.ts` 的 `catPose` 决定，Phaser 猫（`view/art/cat.ts` 的 `CatArt.setPose`，换姿势不重建精灵）与 SVG 头像 `catPortrait` 画同一套形状 `CAT_ART`。待机时缓慢呼吸、偶尔眨眼、摇尾巴，只动猫自己的部件，大小与锚点不变；屏幕外的猫和隐藏场景里的猫暂停，减少动态效果时完全静止。「说说话」头部的小头像仍是旧插画。

顶部半透明浮条是场景切换、时钟、速度键与金币（不再显示品牌栏）；底部浮动工具条是当前场景的入口；提示消息浮在浮条下方，6 秒后淡出；浮动界面都避开 iOS 安全区。时钟旁唯一的速度键点一次在 1× → 2× → 4× → 1× 间循环，只改变浏览器前台每现实秒推进的游戏分钟数（倍率见 `CITY_TIME.speeds`），按设备记在 localStorage（读取时校验），不进世界与存档；进入河畔等小游戏时回到 1× 并禁用（显示"钓鱼 1×"），回城保持 1×。钓鱼 tick 不受影响。没有其他快进入口；地图卡的"等 10 分钟"只在所选猫步行时出现。

浮条下方常驻一行"下一步"引导，随教程进度变化；完整教程、手动"保存进度"放"指引"页，不显示种子等开发信息。"猫咪"页有名册与"邀请 Pepper"；空闲恢复中的猫蜷成一团打瞌睡（读屏读"在休息"），没有休息按钮。"出游"页列出全部水域及解锁条件，点选后在地图定位该水域并安排真实行走，不能直接传送到可钓场景。切换场景关闭面板，单纯开城市面板或刷新快照不切到钓点。

操作卡不提供 Core 会以可知原因拒绝的操作：按钮禁用，卡片下方一行写明原因（由 `GameSession.check` 按 Core 规则试算，文字来自共享的 `ERROR_MESSAGES`）。选猫后点地块打开该地块卡片，在常规操作旁提供"让 <猫名> 走到这里"；点建筑时只显示建筑操作，公寓卡为每只猫列出"入住"。卡片与名册不使用坐标编号，地图也不画行列标签。

到岸后的“进入钓点”先进入预瞄，不创建一竿或消耗资源。玩家可点击水面、调滑杆或启用体感确定两轴落点；只有点击“准备抛竿”才执行 `FISH_BEGIN`、扣除体力/鱼饵并锁定落点。已有一竿时返回钓点恢复同一局，不重复创建或扣费。

面板是覆盖层：手机从浮条下铺到工具条上，桌面为右侧 400px 抽屉；点暗处、返回键或 Esc 关闭。地图默认跟随所选猫，可切总览；点同猫取消选择。操作卡会改变城市可用画面，自动输入每次应重新读取只读格子屏幕位置。

城市画布填满视口（短边 640 逻辑像素），镜头由 `view/city/geometry.ts` 的 `frameMap` 按地图尺寸推导：总览在格子不小于 44px 时整图放入，否则保持 44px 并可拖动平移（移动超过 8px 算拖动，不触发点选）；跟随为总览的 1.5 倍。浮动界面盖住的上下两边不算可用区域：纵向只用顶部浮条与“下一步”引导之下、底部工具条与操作卡之上的开阔带（`view/city/bars.ts` 实测，Harness 点地块用同一函数瞄准）。每个方向上地图放得下就在该区域居中，放不下就夹紧到铺满该区域，不偏向一侧，也没有一行被浮条压住。河畔仍用 640×640 方形画布（体感叠加层与点水瞄准依赖它），画面无边框、最大放到屏宽 1.4 倍并立在抛竿区上方，只裁掉远岸两侧；页面用同色延续天空、远岸与栈桥，因此看起来铺满全屏。

## 内容组织

- 钓具分为配装、补充/设置、线索；包括同行猫、地点、饵、两轴预瞄、旅行、体感、震动和音效。
- "补充 / 设置"里的震动、音效与体感开关并排，文字写明开或关（如"音效：开"）；音效默认开启，选择按设备记住（`cat-city.sound`），不支持 Web Audio 的浏览器显示"此浏览器不支持音效"并禁用。不能振动的浏览器（如 iPhone Safari）的震动开关写作"画面反馈：开/关"，默认开启。
- 鱼篓每页四条，卖鱼/送鱼与补给分开；翻页和页码始终可达。
- 图鉴一页一种鱼，支持选择及前后切换，展示星级、栖息地、长度范围/纪录和品种条件。
- 聊天与回忆分段；对白每页 100 字，长存档回复载入后同样分页，不由其他模块覆盖为全文。
- 保存、旧档显式重置、返回/取消以及输入与发送按钮均在视口可达。

## 钓鱼阶段稳定性

准备、蓄力、等待、咬钩、收线和结算使用相同河面区域与底部操作槽。进度条非活动阶段可隐藏内容但保留位置，按钮不能在指针按住时因阶段重排移动。体感入口不能挡住猫、鱼漂或主要落点。

收线结束时旧按住输入必须释放。随后新出现的准备键只响应从该键开始的新指针操作，旧触摸的抬起/合成 click 不得再开一竿、扣体力或消耗鱼饵；正常键盘激活仍可用。

打开内容、回城、失焦或切后台会暂停并释放钓鱼输入；回城时还没抛出的一竿（按钮版蓄力阶段）自动收起，不扣资源，猫随即空闲恢复体力，已抛出的一竿暂停等你回来；关闭面板或返回后需明确恢复。暂停的是钓鱼 tick，前台城市时间仍推进营业、步行和体力恢复。场景、分页、暂停、预瞄与镜头均为 View 局部状态，不写 World。

## 降级与可访问性

DOM 控件保留名称、焦点、当前选择和文字状态；不只依赖颜色、动画、震动或图标。方向/近远滑杆提供精确调整，鱼竿支持触摸和 Space/Enter；取消触摸或失焦不遗留按住状态。

支持体感的手机默认使用体感钓鱼（触屏设备首次进入河畔显示一次授权卡片，桌面默认按钮）；拒绝权限、非 HTTPS 或无读数时使用按钮流程。允许关闭震动、音效与减弱动画；不能振动的设备在原本振动的时刻改为画面反馈（咬钩、提竿、断线时河面画面轻微震动，鱼线吃紧与上鱼时屏幕边缘暖光一闪），减弱动画时不播放；硬件结果不改 Core。音效（spec 033 F4）用 Web Audio 现场合成、音量轻柔，首次用户手势后才开启音频上下文，页面隐藏时挂起；支持的浏览器设 `navigator.audioSession.type = 'ambient'`，iPhone 静音键可让它静音。真实手机安全区、虚拟键盘、Safari 权限、物理震动、画面反馈强度与实际音色另做实机测试。

### 体感钓鱼（spec 030）

完整设计见 [030 设计](../specs/030-fishing-gestures/design.md)。界面要点：

- 体感进行时隐藏"准备抛竿"、游标条、张力与收线键，底部只留"暂停 / 收竿离开"一行，河面画布尽量放大。
- 瞄准时水面上画落点预测（spec 033 F5，取代原来的竖向力度条）：从竿尖起一条虚线弧落到落点圈，就是抛出后浮漂要飞的路线（与浮漂共用 `water-view.ts` 的 `flightPoint`），随左右瞄准与俯仰力度实时移动；这一方向上 55–80 力度（`FISHING.cast.precisionPower`，即"稳投"）落到的那段水面铺成一条比圈宽、两端圆润的柔和绿区（淡叶绿，边缘略深）。落点圈与虚线弧落在绿区里时变深绿，出了绿区是奶油色；是否稳投用 Core 的 `precisePower`，落点与鱼影同一映射（`water-view.ts` 的 `castPreview`），所以圈罩住鱼影时 Core 也判定碰上。鱼影照常显示，可以把圈对准鱼影；远处的鱼影可能要出了绿区的力度才够得着，这是有意保留的取舍。叠加层右上角（与校准键同一行）标"绿区＝稳投：遛鱼圈更大"。力度仍给读屏：视觉隐藏的 `role="meter"` 读"力度 N，精准区间 55–80"。抛出后提示消息说一次"力度 N · 稳投：遛鱼圈更大"或"力度 N · 不在绿区，没有稳投加成"（`screen.ts` 的 `castNotice`，只认同一竿离开蓄力的那次变化，读档不重播）。按钮版蓄力时水面同样画预测（圈随蓄力往返），开始蓄力的提示写明"在绿区松开＝稳投：提竿和收线的绿区更宽"，抛出后同样说一次；按钮版蓄力前只有落点圈。
- 叠加层覆盖河面的开阔水域：瞄准与等待时显示大号提示；假咬口时提示轻晃并轻震；真咬口显示约屏幕短边三成大小的"！"。
- 遛鱼时显示随竿尖移动、呼吸收缩的圈（鱼在圈内为鼠尾草绿、圈外为红，中线一圈暖光虚线，鱼线从竿尖连到圈心）、朝游向转身的小鱼影（冲刺前泛起涟漪；随累计进度变大、变深，像被拉近）与累计进度；开头 1.5 秒提示稳住；手指在水面拖动可代替倾斜。
- 首次体感钓鱼逐步引导（spec 033 F3）：提示依次为"左右瞄准"（瞄准偏离正前方至少 15°）→"后仰加力"（力度到 65）→"下甩抛竿"（抛出一竿）→"等"！"再上扬"（在"！"时上扬或点水提竿）→"用圈罩住鱼"（Core 在遛鱼中累计进度），每步做到才出现下一步；前三步在瞄准时教，第 4 步在等待与咬钩时，第 5 步在遛鱼时，别的阶段显示平常提示。校准、校准结果、暂停与"往回拉！"优先于引导。校准键下方的"跳过引导"随时结束引导。进度按设备记在 localStorage（`cat-city.fishing-guide`：下一步的名字或 `done`），不进世界与存档；按钮模式没有引导。
- 从未校准过的设备（本地没有调校），第一次能体感瞄准时自动开始校准，提示"校准：向下快甩两次"，每次打开页面至多一次；之后"校准甩竿"键仍在。失败时提示"没感到两次一致的下甩，点「校准甩竿」再试一次"，随后引导继续。
- "钓具 → 补充 / 设置"的开关在体感与按钮之间切换，选择按设备记住；叠加层与开关只改变 View，不修改 World。

## 视觉基调

整体治愈系（2026-09-29 用户确认的风格板）：低饱和暖色，暖纸底，用暖棕细线代替硬边框，配大圆角与带暖色的柔和阴影。开启“减少动态效果”后，所有动画与过渡停止（`styles/base.css` 统一处理）。字体用圆体系统字体栈（`ui-rounded` / SF Pro Rounded，其次系统字体与苹方），不加载网络字体。

界面颜色、阴影与圆角只写在 `src/view/styles/tokens.css` 的 `:root` 变量里，各模块 CSS 只引用变量；尺寸与位置不因配色改变。小字与背景的对比度不低于 4.5:1，大字/粗体不低于 3:1。因此主按钮用比色板“深叶”更深的绿；暖棕 `#8a6f5a` 在暖纸上约 4.3:1，只用于线条与大号图形。猫与插画等场景美术暂未接入 token，留给后续美工改版；小城地图见下文「小城画面」，河景见「池塘画面」。

## 小城画面

小城地图按风格板「小城格子」用 Phaser 代码绘制（`view/art/city-map.ts`）：大圆角格子配暖棕细描线，已购地为鼠尾草绿、未购地更浅；土路是木栈色格子上的手绘虚线，石板路是暖灰底上的短石板；猫咖杏色、猫公寓樱花粉。颜色集中在 `view/art/city-palette.ts`：`TOKENS` 与 `tokens.css` 的同名变量取值相同（单测核对），地图其余颜色由它们混合得出；标签用正文墨色加暖纸描边，任何时段都可读。格子尺寸、位置、点击区域与镜头算法不因画面改变。

光线随游戏时间变化，由纯函数 `cityLight(minute)`（`view/art/city-light.ts`，有单测）给出：5:00 起清晨柔光，9:00 起白天原色，17:00 起傍晚橘光，20:00 起夜晚转为柔和的暮色（草仍是绿、水仍是蓝，单测核对）。景物颜色按时段向色调混合（至多约两成），地图四周的底色一起变化；选中框、步行路线、标签和猫不染色。傍晚与夜晚窗户亮起暖光，夜晚有几只萤火虫。新存档从 0:00 开始，所以第一眼是夜景。

地图只在内容或时段变化时重绘。草丛轻摇和萤火虫漂移是少量独立小物件，每帧只更新它们的角度与位置（`view/art/city-ambience.ts`），不重画整张地图。开启“减少动态效果”时它们静止（萤火虫留在原处发光）；页面打开期间切换该设置也立即生效。

## 池塘画面

河景（钓点画面）按风格板「池塘：傍晚与鱼影」「光线随时间」改版（美术线 G3）。只改画面：Core、鱼影与命中判定、所有几何（`WATER_VIEW`、竿尖、落点与飞行路线、遛鱼平面）不变。

- 颜色集中在 `view/art/river-palette.ts`。与 UI token 同值的颜色（暖纸、鼠尾草、樱花粉、木栈、深叶、暖棕线、水光、提示红、深绿）照抄 `tokens.css` 的值（`TOKEN`，单测核对两边一致）；其余是美术色：由远到近渐深的薄荷湖水、远岸树与倒影、莲叶、萤火。瞄准的落点圈、虚线弧与绿区的颜色（`AIM`）也在这里。
- 四个钓点共用天空渐变、平静的水面与缓慢闪光、暖木栈桥。池塘、芦苇河湾与月光湖有远岸树影及水中倒影；池塘有四片莲叶（一片开樱色小花），月光湖两片莲叶，还有自己的月亮与水中月光（白天淡一些）；芦苇河湾两侧的芦苇在手机上也看得到；海岸是海平线与沙滩。鱼影按体型深浅不一，大鱼更深。
- 光线随游戏时间，时段与小城共用 `cityLight(minute)` 的划分：5:00 起清晨柔光，9:00 起白天，17:00 起傍晚橘色，20:00 起夜晚深蓝，有星星与萤火。`riverLook(钓点, minute)` 给出该时该地的全部颜色，栈桥不受光线影响（按钮与卡片就浮在它上面）；画面与页面背景色带（`riverBackdrop`）用同一份，所以总能接上。只有换钓点或时段变化时才重画天空、水面与远岸。
- 动态：水面闪光淡入淡出、莲叶轻轻起伏、夜晚萤火明灭飘动，都是独立的小对象（补间动画），不重画整幅画面。`prefers-reduced-motion: reduce` 时全部静止（闪光与萤火照常显示，只是不动）。
- 遛鱼：体感叠加层的圈为鼠尾草绿（鱼在圈外为红），带一圈暖光虚线，外缘随张力由金变红（`--tension`）；顶部的累计进度条与按钮版计量条同样是暖色底、深叶填充的圆角条（尺寸位置不变）。上钩的鱼影更深、边缘柔和，随累计进度（`hold / holdTarget`，CSS 变量 `--near`）放大到 1.3 倍并加深，中心不动：放大后宽 11.7%，最小的圈直径 14% 仍能罩住。按钮版河面上的鱼随进度（`progress`）放大到 2 倍、加深，并朝栈桥游近剩余距离的 35%（`water-view.ts` 的 `hookedFish`）。

## 验收

390×844、360×640 与桌面验证 `scrollHeight <= innerHeight`、页面宽度不溢出、面板与重要控件完整在视口。用真实按钮遍历导航、工具分组、装有多条鱼的鱼篓、全部鱼卡和长对白分页；不能只验空状态。

使用真实地图与钓鱼输入，结合 Debug Bridge 状态、回放、Console 和截图核对到岸、资源消费、暂停及刷新恢复。覆盖阶段尺寸稳定与触摸结算穿透，截图需人工查看；完整规则见[测试与 Harness](testing.md)。

体感回归注入模拟 `devicemotion`/`deviceorientation`（Chromium 与 WebKit）：甩竿只在挥出时创建并抛出一竿且扣一次资源，"！"后上扬进入遛鱼，用圈罩住鱼影累计到钓获；切回按钮后叠加层隐藏、按钮流程恢复并按设备记住；新设备自动校准、逐步走完首竿引导，以及跳过引导（其余体感用例预置"已完成引导与校准"）。模拟事件不能代替实机的方向、阈值与手感验证（spec 020）。
