# 界面与输入契约

游戏使用固定单屏，应用高度为 `100dvh`。主要操作不依赖页面或面板纵向滚动；长内容通过分组/分页显示，不能用裁剪隐藏功能。当前奶油色、绿色与代码绘图服务辨认角色和反馈，不改变世界状态。

## 场景与导航

| 场景 | 导航与主操作                                                              |
| ---- | ------------------------------------------------------------------------- |
| 小城 | 建设 / 猫咪 / 聊天 / 出游；地图为主，点地、建筑、猫或水域后显示底部操作卡 |
| 钓点 | 钓具 / 鱼篓 / 图鉴 / 聊天；水面、鱼漂、鱼竿键、绿区条及结果卡承载主要反馈 |

顶部只保留场景、金币与时钟等紧凑状态。详细城市教程放“建设”页；猫咪休息与全城快进是不同操作。“出游”定位水域并安排真实行走，不能直接传送到可钓场景。切换场景关闭面板，单纯开城市面板或刷新快照不切到钓点。

到岸后的“进入钓点”和聊天中的“邀请去钓鱼”都先进入预瞄，不创建一竿或消耗资源。玩家可点击水面、调滑杆或启用体感确定两轴落点；只有点击“准备抛竿”才执行 `FISH_BEGIN`、扣除体力/鱼饵并锁定落点。已有一竿时返回钓点恢复同一局，不重复创建或扣费。

手机（≤760px）在底部显示当前地点四入口，猫卡和内容按需打开。桌面主场景与右侧互动并排，仍保留单屏与同一组控件。地图默认跟随所选猫，可切总览；点同猫取消选择。操作卡会改变城市可用画面，自动输入每次应重新读取只读格子屏幕位置。

## 内容组织

- 钓具分为配装、补充/设置、线索；包括同行猫、地点、饵、两轴预瞄、旅行、体感和震动。
- 鱼篓每页四条，卖鱼/送鱼与补给分开；翻页和页码始终可达。
- 图鉴一页一种鱼，支持选择及前后切换，展示星级、栖息地、长度范围/纪录和品种条件。
- 聊天与回忆分段；对白每页 100 字，长存档回复载入后同样分页，不由其他模块覆盖为全文。
- 保存、旧档显式重置、返回/取消以及输入与发送按钮均在视口可达。

## 钓鱼阶段稳定性

准备、蓄力、等待、咬钩、收线和结算使用相同河面区域与底部操作槽。进度条非活动阶段可隐藏内容但保留位置，按钮不能在指针按住时因阶段重排移动。体感入口不能挡住猫、鱼漂或主要落点。

收线结束时旧按住输入必须释放。随后新出现的准备键只响应从该键开始的新指针操作，旧触摸的抬起/合成 click 不得再开一竿、扣体力或消耗鱼饵；正常键盘激活仍可用。

打开内容、回城、失焦或切后台会暂停并释放钓鱼输入；关闭面板或返回后需明确恢复。暂停的是钓鱼 tick，前台城市时间仍推进营业、步行和休息。场景、分页、暂停、预瞄与镜头均为 View 局部状态，不写 World。

## 降级与可访问性

DOM 控件保留名称、焦点、当前选择和文字状态；不只依赖颜色、动画、震动或图标。方向/近远滑杆提供精确调整，鱼竿支持触摸和 Space/Enter；取消触摸或失焦不遗留按住状态。

体感默认关闭，明确操作后请求权限；界面显示输入模式和失败/无读数状态。任何不支持情况都保留手动完整玩法。允许关闭震动与减弱动画；硬件结果不改 Core。真实手机安全区、虚拟键盘、Safari 权限与物理震动另做实机测试。

### 体感操作面板

体感的模式反馈使用河畔既有底部操作槽，不改变画布大小或新增滚动。`#motion-guide` 只在准备/蓄力阶段、河畔且工具面板关闭时显示；按钮模式隐藏。切换模式和倾斜预瞄不改变 World。

| 输入能力与阶段       | 面板与操作                                                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 请求权限或等待读数   | 显示“体感连接中”，不能提前宣称体感已生效；手动入口可用                                                                         |
| 准备阶段，有倾斜读数 | 显示“体感瞄准”，瞄准点与方向/远近文字同步变化；明确点击准备后才开竿                                                            |
| 仅倾斜可用           | 说明“倾斜瞄准，按钮抛竿”，不暗示能够甩竿                                                                                       |
| 仅动作读数可用       | 说明拖动瞄准，准备后体感甩竿                                                                                                   |
| 蓄力阶段，有动作读数 | 点击“准备抛竿”后直接进入 4 秒甩竿窗口，显著展示落点锁定、力度与绿色目标；无需再点一次准备。甩竿键至少 44px，手动蓄力键仍可操作 |
| 等待与收线           | 等待时留意鱼漂；收线继续用按钮控制张力，不改为二维追圈                                                                         |
| 提竿，有倾斜读数     | 显示二维目标圈，左右及前后倾斜移动输入点；连续留在圈内达到所需时间后自动提竿，按钮仍可接管                                     |
| 暂未收到读数         | 保留监听并显示等待提示，手动入口可用；迟到的有效读数可恢复体感                                                                 |
| 关闭或拒绝           | 恢复按钮操作；模式提示说明原因，不扣体力、不消耗鱼饵                                                                           |

主场景提供至少 44px 的“重新校准体感”按钮，有倾斜读数后可反复使用。尚未准备抛竿时，校准将预瞄归到水池中央（方向 0、近远 50），以当前握姿为新零点；旋转屏幕后收到新读数即可在主界面重新校准。进入蓄力或已经抛投后不改变锁定的落点。校准只改变本地预瞄和输入基准，取消待甩动作及其已排定的力度结算，不修改 World 或消耗资源。

自动进入甩竿窗口只发生在新一竿明确准备时，不能由刷新、返回场景或迟到读数触发。取消或超时后可点甩竿键重试；失焦、开工具或回城也取消待甩动作。已开始一竿后预瞄锁定，不以倾斜或重新校准改变世界中的抛投参数。传感器输入仍经原有 `FISH_BEGIN` / `FISH_CAST` 与输入命令结算，面板自身只呈现状态。

提竿圆圈使用同一个底部操作槽，不挤动水面和按钮。输入点初始在圈外，左右/前后倾斜只改变二维控制坐标；校准保留点位。圈内状态和连续稳定进度有文字/进度反馈，离圈清零，限时内未完成仍会脱钩。实际命中由 Core 验证 `FISH_MOTION_CONTROL`，不能靠 View 自报成功。“切回按钮提竿”首次按下只接管并显示原有绿区条，保留暂停状态，不对此前隐藏的游标盲目判定提竿；随后再按才是手动提竿。关闭体感或无倾斜能力时沿用手动玩法。

设备姿态跨越 Euler 角表示边界时，输入连续解缠，不把传感器数值换支当作突然反向。画面边界采用饱和限制；继续朝外倾斜不会把点跳到另一侧。屏幕方向改变仍需重新校准。

## 验收

390×844、360×640 与桌面验证 `scrollHeight <= innerHeight`、页面宽度不溢出、面板与重要控件完整在视口。用真实按钮遍历导航、工具分组、装有多条鱼的鱼篓、全部鱼卡和长对白分页；不能只验空状态。

使用真实地图与钓鱼输入，结合 Debug Bridge 状态、回放、Console 和截图核对到岸、资源消费、暂停及刷新恢复。覆盖阶段尺寸稳定与触摸结算穿透，截图需人工查看；完整规则见[测试与 Harness](testing.md)。

体感回归从真实地图岸边/聊天邀请入口验证预瞄、准备和抛投的顺序与一次资源消费，并在 360×640 和 390×844 覆盖开启即出现面板、等待读数、两轴瞄准、时钟更新后模式保持、准备后落点锁定、部分传感器权限、力度显示与实际抛投一致，以及关闭/失败后手动操作恢复。模式切换前后画布边界必须一致；浏览器模拟传感器通过不等同于 Safari 硬件实测。

主场景校准在 Chromium 与 WebKit 验证两次预瞄归中、屏幕旋转后的基准恢复、已锁定落点不变，以及校准取消已排定甩竿结算；检查按钮完整可点、画布不位移、世界状态不变并保留截图。

二维提竿验证从真实岸边抛投、圈外等待、暂停/校准保持状态、两轴入圈后自动提竿及手动收线；同时验证关闭体感和按键接管能完成同一竿。边界回归使用连续的等价姿态序列，不能用不连续的正负角跳变代替真实过界。
