# 城市地图、建设与步行

当前循环：买地 → 选择建筑 → 连路 → 选择猫咪步行 → 到岸钓鱼 → 卖鱼/送礼 → 收入、体力恢复与扩建。所有规则由 Core 决定，地图与操作卡只展示状态并提交命令。

## 地图与选择

- 初始 10×10、1000 金币；Mochi 出生在当前地图种子的池塘岸边，选靠近起始道路的未购买草地。坐标从 0 开始，只在 Core 与测试中使用；界面不显示坐标编号，用地图上的选中框、名称和路线表示位置。
- 新浏览器世界选择 uint32 种子；测试显式指定。独立 RNG 生成右侧 4–6 格池塘、西侧南北贯通的河、北部小湖及东南海岸，草地连通且有可达岸边。
- 中央 `x=3..6, y=3..6` 土地已拥有，十字土路连接起始城区。水格不能购买、建设或步行；未购买草地可以步行，购买控制建设权。
- `map.tiles` 保存地形、归属和路面，载入不重新生成。画面像素与逻辑格分离，当前建筑占 1×1 格。
- 点猫选中 → 点地块打开它的卡片，选“让 <猫名> 走到这里”安排步行 → 再点同猫取消选择。点地块总是先显示该地块的建设操作，点建筑只显示建筑操作（公寓卡为每只猫列出“入住”）。默认镜头跟随伙伴，提供总览；选择和镜头本身不改变世界。

## 建设与经营

| 动作     | 当前规则                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------- |
| 买地     | 草地 50 金币/格                                                                                     |
| 猫咖     | 300 金币；每完整营业 60 分钟收入 10，每家独立保存余数                                               |
| 猫公寓   | 250 金币；最多 2 只猫登记住所，无营业收入                                                           |
| 搬移     | 免费；保留建筑 ID、建造时间、营业余数、住所引用，原路面保留                                         |
| 接路网   | 建造/搬移不铺路：目标格必须紧挨一格连到起始路口的道路，否则拒绝（`ROAD_NOT_CONNECTED`），先自己铺路 |
| 铺土路   | 30 金币/格；需已拥有草地且无建筑                                                                    |
| 升级石路 | 已有土路花 40 金币/格升级                                                                           |
| 拆除道路 | 全额退还：土路 30、石路 70（铺路+升级）；起始路口与建筑唯一连接不可拆                               |

建筑不能覆盖猫、道路、水或其他建筑。购买与建设是两个明确动作；费用、路面与建筑修改原子提交，失败不扣费、不留下半截道路。拆路（`REMOVE_ROAD`）后该格可再建设；拆后任一建筑不再连到起始路网或拆的是起始十字路口时拒绝（`ROAD_IN_USE`）。猫站在该格或路线经过都不阻止拆路：道路只影响步速，已排定的下一步仍合法。当前没有建筑拆除、升级和石路降级。指引页的教程收益只描述第一家猫咖。

## 一个时钟上的移动与体力恢复

`WALK_CAT` 和 `TRAVEL_TO_FISHING_SPOT` 只安排路线，不立即推进时间或传送。确定性最短耗时寻路避开水、建筑和其他猫。进入草地/土路/石路分别用 10/5/3 游戏分钟，每完成一格扣 1 体力；路线和绝对下一步时间持久化。

新游戏从第 1 天 7:00 开始（`CITY_START.minute`）。前台时钟或显式推进才推动移动。浏览器前台每现实秒推进 1、2 或 4 游戏分钟（时钟旁速度键，按设备记住，小游戏中固定 1×）；所选猫步行时，操作卡可等 10 分钟。新障碍导致重新寻路，无法继续时记录 `WalkBlocked`；猫之间不重叠。体力为 0 时保留暂停路线，恢复体力后自动继续。

猫空闲时自己恢复体力：不在钓鱼、也不在迈步（体力耗尽而停下的路线算空闲）时，游戏时间每到整 10 分钟恢复 5 体力，在自己的公寓旁恢复 10，上限 100。没有休息指令，猫随时可以调遣（Core 的 `catIdle` 判定，界面据此让猫蜷成一团打瞌睡）。收入、步行与恢复都依赖 `world.minute`，后台不补离线时间。

心情（0–100，新猫 70，spec 032）也走同一时钟：每到整点向这只猫的平静点靠拢 2（不越过），在自己公寓旁再 +1；平静点是 60 加关系等级的奖励（见下）；聊天拿到每小时一次的关系增长时 +2；步行中体力降到 0 的那一步 −5。钓鱼与送礼的心情见[钓鱼设计](fishing-design.md)。档位：≥80 开心、50–79 平静、30–49 有点闷、<30 低落（`moodBand`）；规则对话的闲聊按档位换语气，事实回忆不变。低落不减收益、不禁止行动。

关系（`playerBond` 0–100，spec 036）：聊天、送鱼、和这只猫一起钓到鱼各 +1，三者共用每游戏小时一次的上限，从不下降。等级由它推导、不入档（`content/care.ts` 的 `BOND_LEVELS` 与 `bondLevel`）：初识 0、熟悉 5、信任 15、亲密 30、家人 60。初识以上每级把心情平静点提高 3（`moodRest`：60/63/66/69/72），只奖励不惩罚。规则对话的闲聊按等级多一句收尾，事实回忆不变。1× 速度下每游戏小时是现实 1 分钟，最快约 4/14/29/59 分钟到达各级。

## 到岸才开始钓鱼

池塘、河、湖、海的四邻草地构成岸边集合。新世界的 Mochi 已在池塘岸边，点池塘即可进入钓点；去其他水域时，点水域或“出游”再安排猫步行。真实位置在岸边、没有未完成路线、不在活动中且满足水域解锁条件时才能开始钓鱼。

切换菜单、预览水域或改写已到达地点字段不能替代实际位置。连续在同一岸边开钓无需重新旅行；换猫按其独立坐标与路线检查。鱼池和开放条件见[钓鱼设计](fishing-design.md)。

## 验证边界

地图测试检查种子分布、连接性、起始路网和岸边；命令/模拟测试检查原子拒绝、碰撞、道路耗时、能量、时间分块等价和存档续走。Harness 通过真实格子点击完成购地、路面、公寓、猫咖搬迁和岸边活动，开发桥仅帮助观察与定位输入。保存及证据规则见[架构](architecture.md)和[测试](testing.md)。
